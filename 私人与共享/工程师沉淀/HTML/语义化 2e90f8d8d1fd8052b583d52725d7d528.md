# 语义化

## 什么是语义化

1. 每一个 HTML 元素都有具体的含义
    
    a: 超链接
    
    p: 段落
    
    h1: 一级标题
    

1. 所有元素与展示效果无关

> HTML 元素本身几乎不定义“视觉样式”，大多数默认展示效果确实来自浏览器的默认样式表；
> 

> 但 HTML 元素并非与展示完全无关，它定义了语义、布局类型、交互能力与可访问性，这些不能被简化为“只是 CSS”。
> 

选择什么元素，取决于**内容的含义**，而不是显示出的效果

## 为什么需要语义化

1. 为了让搜索引擎更加理解我们的页面
    
    搜索引擎会每隔一段时间，从整个互联网中抓取页面源代码，存放到数据库然后用户使用的时候就是抓取‘
    
    所以让搜索引擎更加理解我们的页面、优化SEO、提高搜索排名
    
2. 为了让浏览器理解页面
    
    阅读模式：忽略菜单，只剩下正文
    
    语音模式：方便残疾人士等等

# 表单元素及配合元素

# 表单元素

一系列元素，主要用于收集用户数据

## input

输入框

### type属性 - 输入框类型

1. text 普通文本输入框
2. password 密码输入框，会用字符代替输入内容
3. date 日期选择器，可能会有兼容性问题
    
    可替换元素，样式无法更改、跟随系统
    
    time 只选择时间
    
    week 只选择周
    
4. search 搜索框
5. range 滑块
    
    可以设置 min 和 max
    
6. color 颜色选择
7. number 数字输入框，只能输入数字
    
    step 每次更改的值
    
8. radio 单选框
    
    通过 name 分组
    
9. checkbox 多选框
    
    通过 name 分组
    
10. file 选择文件

#### selected

布尔属性，表示默认选中

### value属性 - 输入框的值

### placeholder - 提示文本

### 通过 input 制作按钮

现代基本不用了，为了兼容古老浏览器

reset 重置按钮

submit

buttom

```
<input type="reset" value="重置">
<input type="submit" value="提交">
<input type="button" value="按钮">
```

## select

下拉列表选择框

通常和 option 元素配合使用（select元素子元素只能是option 或 optgroup）

option 元素支持 selected 布尔属性

option 元素外面还支持套一层 optgroup 进行分组

optgroup 元素支持传入 label 设置分组名称

想要支持多选的话可以在 select 中传入 multiple

## textarea

文本域，多行文本框

### cols

列数

### rows

行数

更推荐用 CSS 控制

默认显示内容是直接写在开闭之间

## button

type属性

1. reset
2. submit
3. button

默认是 submit 提交按钮

# 表单状态

readonly 布尔属性，这个表单元素是否只读，不会改表表单显示样式

disabled 布尔属性，是否禁用，会改变样式，并且会影响JS

灰色蒙层

# 配合表单元素的其他元素

## label

标签、表单标签

用于 **描述**、关联 表单控件

显式关联：for 属性写的表单元素id ，通过 for 属性让 label 元素关联表单元素

```css
<input type="radio" name="sexGroup" id="male">
<label for="male">男</label>

<input type="radio" name="sexGroup" id="female">
<label for="female">女</label>
```

隐式关联：直接将 input 放在 label 里面

```css
    <label>
        <input name="sex" type="radio">
        男
    </label>
```

## datalist

数据列表

该元素本身不会显示到页面，通常和普通文本框配合

子元素和 select 一样只能是 option

在 datalist 配置 id 后，在 input 的 list 属性输入 datalist的id

## form

通常会将整个表单元素，放置 form 元素的内部，作用是当提交表单时，会将 form 元素内部的表单内容以合适的方式提交到服务器

即做**校验**等等

action 属性链接地址提交给服务器端验证

method 提交方式

GET

POST

form 内部的配置 name 后到时候会以 url 参数的形式传过去（不写就没有）

即 **{name}={value}**

所以如果用 select 的话记得在 option 中配置 value

```css
?id=hello&password=123&selected=A&selected=B
```

## fieldset

表单分组

field 字段 

set 集合

在需要在同一组的表单元素外面通过 fieldset 包一层

支持子元素 legend 设置该分组标题

# 常见场景

- 浏览器 DOM事件系统
    
    **EventTarget 就是浏览器自带的 EventBus**
    
- React事件系统（根元素收集）
- Node.js
    
    ```jsx
    const EventEmitter = require("events")
    
    const bus = new EventEmitter()
    
    bus.on("msg", data => {
      console.log(data)
    })
    
    bus.emit("msg", "hello")
    ```

# 域名 DNS

域名👉 `www.baidu.com`

域名的作用是**帮助人类记忆**网站地址，有了域名，就不用去记IP地址了

域名的类型有以下几种：

- 根域名：`.`
- 顶级域名：`.cn .com .net .us .uk .org ...`
- 二级域名：`.com .gov .org .edu 自定义 baidu jd taobao ...`
- 三级域名：`自定义 www.baidu.com www.jd.com www.taobao.com`
- 四级域名：`自定义 www.pku.edu.cn mail.internal.jd.com`

一般来说，购买二级域名后，三级、四级域名都是可以免费自定义的

# DNS

域名虽然有助于记忆，但是网络传输和域名没有半毛钱关系

**第三层网络层 网络传输必须依靠IP**

所以，必须有一个东西，能够将域名转换成IP地址，这个东西就是DNS服务器，翻译成IP地址的过程称之为**域名解析**

全世界认可的DNS服务器一共有三种，外加一种局部使用的本地DNS服务器，一共四种。

![image.png](%E5%9F%9F%E5%90%8D%20DNS/image.png)

1. 本地查询阶段
    1. **浏览器**缓存
    2. **操作系统**缓存
    3. **本机hosts**文件
2. 本地域名服务器：如果本地查询未命中，客户端会向本机配置的DNS服务器、即**递归解析器**发请求，如果递归服务器有缓存，那么就直接返回，
    
    否则开始向上级DNS系统递归地查询、总共**来回三趟**
    
3. **根**域名服务器：根据 **根域名**、如.com .cn …，返回目标的顶级域名服务器的IP地址给递归解析器
4. **顶级**域名服务器：根据 **顶级域名**、如 sankuai.com …，返回目标的权限域名服务器的IP地址给递归解析器
5. **权威**域名服务器：最终返回结果IP地址

为了使得解析速度更快、查询的节点更少，上述每个节点都可能设置**高速缓存**来加速解析

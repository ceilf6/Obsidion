# infer

infer 是 TypeScript 里**配合条件类型使用的“类型推断变量”关键字**。

它的作用可以理解成：

> 在类型匹配过程中，
> 
> 
> 把某一部分**类型**“抓出来”并命名
> 

---

## **先看最经典的例子**

```tsx
type GetReturnType<T> = T extends (...args: any[]) => infer R ? R : never
```

意思是：

- 如果 T 是一个函数类型
- 形如 (...args: any[]) => 某个返回值
- 那就把这个“返回值类型”推断出来，命名为 R
- 最终返回 R
- 否则返回 never

### **使用**

```
type A = GetReturnType<() => string>   // string
type B = GetReturnType<() => number>   // number
type C = GetReturnType<string>         // never
```

这里的 infer R 就是在说：

> “如果你能匹配到这个函数类型，请顺便把返回值类型提取出来，叫做 R。”
> 

---

# **infer**

# **只能用在哪？**

它**只能出现在条件类型的 extends 判断里**。

也就是这种结构：

```
T extends 某种类型模式 ? infer出来的结果 : 另一种结果
```

比如：

```
type X<T> = T extends Promise<infer U> ? U : T
```

---

# **常见用途**

## **1. 提取 Promise 里的值类型**

```
type UnwrapPromise<T> = T extends Promise<infer U> ? U : T
```

```
type A = UnwrapPromise<Promise<string>> // string
type B = UnwrapPromise<number>          // number
```

---

## **2. 提取数组元素类型**

```
type ElementType<T> = T extends (infer U)[] ? U : T
```

```
type A = ElementType<string[]> // string
type B = ElementType<number[]> // number
type C = ElementType<boolean>  // boolean
```

也可以写成：

```
type ElementType<T> = T extends Array<infer U> ? U : T
```

---

## **3. 提取函数参数类型**

```
type GetParams<T> = T extends (...args: infer P) => any ? P : never
```

```
type A = GetParams<(a: string, b: number) => void> // [string, number]
```

这里 infer P 推断出来的是参数元组。

---

## **4. 提取构造函数实例类型**

```
type GetInstanceType<T> = T extends new (...args: any[]) => infer R ? R : never
```

```
class Person {
  name = 'Tom'
}

type A = GetInstanceType<typeof Person> // Person
```

---

# **为什么需要**

# **infer**

# **？**

因为有时候你不是想“判断是不是某种类型”，而是想：

> **如果是这种类型，把里面的一部分拿出来。**
> 

比如：

- Promise<string> 里的 string
- string[] 里的 string
- (a: number) => boolean 里的 boolean
- [number, string] 里的每一项
- 模板字符串类型里的某一段

这时候 infer 就特别有用。

---

# **你可以把它理解成“类型层面的解构”**

像 JS 里你会这样解构：

```
const [first] = arr
```

而在 TS 类型里，infer 有点像：

> “如果这个类型长这样，那我把其中某一块拆出来。”
> 

例如：

```
type First<T> = T extends [infer A, ...any[]] ? A : never
```

```
type A = First<[1, 2, 3]> // 1
type B = First<[string, number]> // string
```

这里就是在“解构元组的第一项”。

---

# **再看几个进阶例子**

## **提取元组最后一项**

```
type Last<T extends any[]> = T extends [...any[], infer L] ? L : never
```

```
type A = Last<[1, 2, 3]> // 3
type B = Last<[string, boolean]> // boolean
```

---

## **提取字符串模板中的一部分**

```
type GetPrefix<T> = T extends `${infer P}_${string}` ? P : never
```

```
type A = GetPrefix<'user_name'> // 'user'
type B = GetPrefix<'id_value'>  // 'id'
```

这里 infer P 提取的是模板字符串里 _ 前面的部分。

---

# **infer**

# **不是运行时功能**

这个很重要：

- infer **只存在于 TypeScript 类型系统里**
- **不会出现在运行时**
- **不会生成 JS 代码**
- 只是编译阶段做类型推断

---

# **和泛型**

# **<T>**

# **的区别**

很多人一开始会混淆。

## **泛型**

## **T**

是你**主动传入/声明**的类型参数：

```
function identity<T>(arg: T): T {
  return arg
}
```

这里 T 是函数的泛型参数。

---

## **infer R**

是你在**条件类型匹配时临时推断出来**的类型变量：

```
type GetReturnType<T> = T extends (...args: any[]) => infer R ? R : never
```

这里的 R 不是外面传进来的，而是在匹配成功后临时“推断”出来的。

---

# **一句话总结**

infer 的核心作用就是：

> **在条件类型中，从某个复杂类型里提取出一部分类型。**
> 

你可以把它记成：

> infer = 在类型匹配时“定义一个待推断的局部类型变量”
> 

---

## **最后给你一个最实用的记忆模板**

```
type XXX<T> = T extends 某种结构<infer U> ? U : never
```

比如：

```
type UnwrapArray<T> = T extends Array<infer U> ? U : never
type UnwrapPromise<T> = T extends Promise<infer U> ? U : never
type FnReturn<T> = T extends (...args: any[]) => infer U ? U : never
```

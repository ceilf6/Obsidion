# 自审

两条线，第一条是学业、实习、传统软件开发写代码等等，第二条就是AI相关

首先第一条线，大一大二我主要在学校争取高绩点，每年都能拿到奖学金，同时在学业之余我也参加实验室自己开创了一个课题 … ，后面我感觉学校中技术相对比较落后，我就自学了前端三大件，看了浏览器相关的、网络相关的知识，以及出于好奇例如函数组件是如何通过hook保存状态的？看了框架Vue2、Vue3和React的部分源码，在25年6月去七牛实习，

然后第二条和AI相关的线，首先从使用上，从23年GPT大火、到后面Coze等工作流编排平台，只要有新东西出现我就去折腾一下，首先一方面是提高效率出发、另一方面是在使用过程中去培养产品思维，例如最近的龙虾，我克隆到mac上跑通后在飞书开发者平台上起了个应用机器人打通了龙虾到飞书的链路，使用过程中有了一些感受，首先我感觉龙虾和别的智能体能力上没有什么本质提升，我就问自己为什么龙虾能这么火但是别的像Claude Code没有那么火出圈，我想到的最重要一点就是他产品封装的好，通过网关统一打通第三方平台壁垒让使用者更加方便，然后使用过程中我还想到一些idea，向未来或许我能写个插件，方便使用者在第三方应用例如飞书上面，直接框选一段文字之后点击加入记忆或者规则后，直接能写入对应智能体的md文件中，而不需要和他说“请添加规则”或者“请记住”，但是未来也许操作系统底层就是一个智能体那从操作系统层面就支持这种能力

好像有点扯远了，后面我讲讲学习AI相关的，首先我认为AI

总之，这个时代是传统和AI两条线碰撞的时代，一方面学习真的很方便了，只要自己不给自己设限，任何东西让AI去爬虫、去梳理都能慢慢理清楚。另一方面大模型能力不断增强，未来智能体能替代的任务越来越多，作为一名工程师我认为不断学习，培养产品、业务思维，了解新技术并学会支配AI去找寻实现需求的最优解，是未来的趋势。有些人说前端已死但是我感觉只对了一半，因为 由于前端技术的更新频率高、前端工程师自古以来就是不断学习新技术的，所以只能说前端可能死了、但是前端工程师肯定会通过不断学习通过智能体开发工程师、产品型工程师等身份持续向前，这也是我对自己未来的一个基础要求

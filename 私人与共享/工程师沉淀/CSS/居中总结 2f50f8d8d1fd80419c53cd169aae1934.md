# 居中总结

居中指的是 盒子在其包含块中居中

# 水平居中

## 行盒、行块盒水平居中

直接设置行盒、行块盒父元素

```css
text-align: center;
```

## 常规流块盒水平居中

块盒只可能是常规流

1. 定宽（因为宽度的吸收能力比 margin 强）
2. 设置左右 margin 为 **auto**

## 绝对、固定定位元素水平居中

1. 定宽（因为宽度的吸收能力比 margin 强）
2. 设置左右坐标为0
3. 设置左右 margin 为 auto

> 固定定位是绝对定位的特殊情况 - 包含块是视口
> 

# 垂直居中

## 单行文本的垂直居中

设置文本所在元素的行高，为整个区域的高度

## 行块盒、块盒内多行文本的垂直居中

没有完美方案

设置 包含块上下内边距相同

最完美的垂直居中方案是下面

## 绝对定位的垂直居中

1. 定高
2. 设置上下坐标为0
3. 设置上下 margin 为 auto

# 块级格式化上下文 BFC

Block Formatting Context 简称 BFC

是一块**独立的渲染区域**，规定了在该区域中， **常规流块盒** 的布局

（例如 可以通过 浮动产生 BFC ，管理其内部常规流）

视觉格式化模型包含了块级格式化上下文，而**块级格式化上下文决定了常规流块盒的布局规则**

- 常规流块盒**在水平方向上，必须撑满包含块**
- 常规流块盒**在包含块的垂直方向上依次摆放**
- 常规流块盒**若外边距无缝相邻，则进行外边距合并**
- 常规流块盒的**自动高度和摆放位置，无视浮动、定位元素**

# 产生BFC

“BFC是一个**独立的渲染区域**”，这个区域由某个HTML元素创建，以下元素会在其内部创建BFC区域

1. **根元素 即 html 元素**，覆盖了网页中所有的元素
2. **浮动** 和 **绝对定位** 元素
    
    float , position: absolute
    
3. **overflow** 不为 visible 的块盒（即修改过、不为默认值）
4. 行块盒 **display: inline-block**

# BFC效果

“**独立**的”：不同的BFC区域在进行渲染时互不干扰

创建 BFC 的元素，隔绝了其内部和外部的联系，内部的渲染不影响外部

为保证独立 ⇒ 具体规则：

1. 创建 BFC 的元素，**其自动高度需要计算浮动元素**（例如可用 **overflow: hidden 清除浮动**）
    
    注意只有清除浮动，像定位元素已经完全脱离了常规流
    
2. 创建 BFC 的元素，它的边框盒**不会和浮动元素重叠**（侧边栏固定后自适应)
3. 创建BFC的元素，不会和它的子元素进行外边距合并；不同BFC中的元素不会外边距合并。即**只有是在同一个BFC中的兄弟才可能外边距合并**
    
    那么就可以通过**创建 BFC 来解决外边距合并**

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        .container {
            background-color: #bf91f3;

            /* position: absolute; */
            /* float: left; */

            /* 副作用最小的 */
            overflow: hidden;
        }

        .container .item {
            background-color: lightblue;
            width: 200px;
            height: 100px;
            margin: 10px;
            float: left;
        }

        /* 法1. clear
        .clearfix::after {
            content: "";
            display: block;
            clear: both;
        } */
    </style>
</head>
```

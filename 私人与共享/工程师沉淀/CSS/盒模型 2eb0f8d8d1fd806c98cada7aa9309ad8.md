# 盒模型

每个元素在页面中都会生成一个矩形区域（盒子）

盒子类型 - CSS样式（抛弃原先的行级元素、块级元素的说法）

1. 行盒
    
    display: inline
    
2. 块盒
    
    display: block
    

行盒在页面中不换行

块盒独占一行

浏览器默认样式表设置的块盒：容器元素、h1~h6、p
常见的行盒-和内容相关的：span、a、img、video、audio（display样式属性的默认值也是 inline ）

## 盒子的组成部分

无论行盒还是块盒，都由下面几个部分组成，由内而外分别是

1. 内容 content
    
    width、height 设置的是盒子内容的宽高
    内容部分通常叫做整个盒子的内容盒 content-box
    
2. 内边距 padding
padding-left、padding-right、padding-top、padding-bottom
属性简写、速写 padding: **上 右 下 左 （顺时针**，上=下、右=左时可以只写两个）
    
    盒子边框到盒子内容的距离，不设置默认是 0
    
    内容区+填充区 = 填充盒 padding-box
    
3. 边框 border
    
    边框 = 边框样式 border-style 默认是none
    
    + 边框宽度粗细 border-width 也是简写属性 = border-上 右 下 左-width
    
    + 边框颜色 border-color 默认是字体颜色
    
    内容+填充+边框 = 边框盒 border-box
    
4. 外边距 margin
    
    边框到其他盒子的距离
    
    margin-top、margin-left、margin-right、margin-bottom
    
    也同样可以速写 margin: 上 右 下 左
    

可以在 Computed 中看

# 真题：五层盒模型

由内到外还是上面的四层

多了一层 background背景绘制层 ，主要属性是

background-origin 决定从哪里开始绘制，默认是 padding-box即内边距盒子-填充盒

background-clip 决定绘制到哪里

## 应用

### 改变宽高范围

量取的是设计稿的边框盒宽高，但设置 width 和 height 的是内容盒宽高

导致盒子实际大小大于设计稿

解决方案

1. 精确计算
2. CSS3中
box-sizing: 属性默认是 content-box 也就是内容盒
    
    可以设该属性为 **border-box** 改变宽高的影响范围为边框盒，也就是实际量取的
    

### 改变背景颜色覆盖范围

默认情况下，背景覆盖边框盒

可以通过 background-clip 修改

```html
.back-cover {
    border: 10px dashed red;
    background-color: green;
    background-clip: content-box;
}
```

### 溢出处理

当宽、高都规定的时候，内容可能会超出范围，虽然还能显示，但是超出了边框看起来很丑，这是因为 **overflow** 属性默认是 visible

可以进行修改

1. scroll 滚动条
2. auto 自动：当盒子范围能放下内容时没有滚动条，如果放不下就会显示

但是**macOS 的滚动条系统级设置默认是「滚动时才显示」**

```html
        /* 强制在 macOS 上始终显示滚动条 */
        /* track thickness */
        .container::**-webkit**-**scrollbar** {
            -webkit-appearance: none;
            /* 竖向滚动条粗细 */
            width: 8px;
            /* 横向滚动条粗细 */
            height: 8px;
        }

        /* scroll box */
        .container::-webkit-scrollbar-thumb {
            border-radius: 4px;
            background-color: rgba(0, 0, 0, .5);
        }

        /* track color */
        .container::-webkit-scrollbar-track {
            background-color: rgba(0, 0, 0, .1);
        }
```

### 断词规则

word-break

会影响文字在什么位置被截断换行

取值

1. normal：普通，CJK（中国、日本、韩国）字符在文字位置截断；非CJK字符在单词位置截断
2. break-all：截断所有，所有字符都在文字处截断
3. keep-all：所有字符都在单词处截断（空格区分）

### 空白、省略处理

文字太多用 … 省略处理

white-space: nowrap; 超出时强制不换行 - 所以只能处理单行文本（多行得用JS处理）

overflow: hidden; 溢出隐藏

text-overflow: ellipsis; 文本溢出用圆点代替

- white-space 还能设为 pre 时就不会进行空白折叠

# 概述

CSS规则 = 选择器 + 声明块

选择器：选中元素

## 选择器

1. ID选择器
    
    前面是 # ，选中对应 id 值的元素
    
    ```html
    /* ID选择器和变量名一样不能以数字开头 */
    #text1 {
        color: red;
    }
    ```
    
2. 元素选择器
    
    直接书写元素名称，选择页面中所有同名元素
    
    ```html
    h1{
    
    }
    ```
    
3. 类选择器
    
    以 . 开头，可以间隔空格选择多个类
    
    ```html
    .red {
    
    }
    
    .big {
        font-size: 3em;
    }
    
    <p class="red big">class="red big"</p>
    ```
    

**class 可以重复使用，id 在一个文档中必须唯一**

## 声明块

出现在大括号 { } 中

声明块中包含很多属性 - 样式规则

## CSS代码位置

1. 内部样式表
    
    书写在 style 元素中，这个元素通常放在 head 中，让浏览器优先加载
    
    ```html
    <style>
    
    </style>
    ```
    
2. 内联样式表 - 元素样式表
直接在对应元素的开始标签中写属性 style（所以不需要选择器，直接写属性）
3. 外部样式表
也是在 head 中 link 进来
    
    ```html
    <link rel="stylesheet" href="./css/index.css">
    ```
    
    <link> 标签**一定要加 rel="stylesheet"，浏览器才会把它当成 CSS 文件加载**
    

### 外部样式表优点

1. 外部样式表可以实现样式复用
2. 有利于浏览器缓存，从而提高页面响应速度
浏览器会直接命中已经读取过的样式表内容
3. 有利于代码分离，更容易阅读和维护

# class

super 是 ES6 引入用于

1. 子类调用父类构造函数
    
    ```jsx
    class Animal {
      constructor(name) {
        this.name = name;
      }
    }
    
    class Dog extends Animal {
      constructor(name) {
        super(name); // 调父类构造函数
      }
    }
    ```
    
2. 调用父类方法
    
    ```jsx
    class Animal {
      speak() {
        console.log("animal");
      }
    }
    
    class Dog extends Animal {
      speak() {
        super.speak(); // 调父类方法
        console.log("dog");
      }
    }
    ```

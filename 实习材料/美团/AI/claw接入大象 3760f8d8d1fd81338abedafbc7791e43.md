## 使用时注意事项

- 例如如果通道是对接 codex ，那么不要在 codex 中打开对应对话，会导致提前终止
- 通道是通过 state 文件管理上下文，可以通过 11 session 进行管理

## 附上常用命令

```
// 代码块
catpaw-channel-daxiang start     # 后台启动
catpaw-channel-daxiang stop      # 停止
catpaw-channel-daxiang status    # 查看是否在运行
catpaw-channel-daxiang logs      # 实时查看日志（Ctrl+C 退出）
```

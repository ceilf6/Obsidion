# 避免样式导致重渲染

1.

```jsx
  const titleContentStyle = useMemo(() => ({ flex: 1 }), []);
  <View style={titleContentStyle}>
```

2.

```jsx
  lackStockTip: {
    flex: 1,
  },
  
  <View style={styles.lackStockTip}>
```

你这个判断是对的：这类**静态样式**更推荐写成 `style={styles.lackStockTip}`，而不是组件内 `useMemo`。

- 样式定义位置：[style.ts:53](https://www.notion.so/Users/ceilf6/Desktop/ka-mop-max-duo/packages/ka-mop-duo-shelf-mix/src/ShopCustomization/components/ChooseProductAndSku/components/TitleLine/style.ts:53)

原因分两层：

1. 为什么“要这样写”
    
    `styles.xxx` 是模块级常量（通过 `remStyleSheet` 统一管理），符合你们规则对“样式集中管理/可静态分析”的要求。
    
    `useMemo(() => ({ flex: 1 }), [])` 虽然也能稳定引用，但依然是“组件内创建样式对象”的模式，很多规范会要求静态样式必须放到 `style.ts`。
    
2. 为什么能减少不必要重渲染
    
    `style={{ flex: 1 }}` 每次 render 都是**新对象引用**。
    
    如果这个 `style` 继续传给 `React.memo/PureComponent` 子组件，浅比较会认为 props 变了，从而触发额外渲染。
    
    `styles.lackStockTip` **引用是稳定**的，同样 props 下浅比较可通过，子组件可跳过渲染；同时也减少样式 diff/flatten 的额外开销。
    

补一句：

- 静态样式：优先 `styles.xxx`
- 动态样式（依赖 props/state）：再考虑 `useMemo`

### 三、DevTools Code 平台（[git.sankuai.com](http://git.sankuai.com/)）接口

美团内部 Git 代码托管平台（Bitbucket Server），有两套调用方式：

### 3.1 方式一：Cookie 认证（适合个人工具/快速调用）

**Base URL**: `https://dev.sankuai.com`**认证**: 浏览器 Cookie（`f32a546874_ssoid`, `devtools_ssoid`, `JSESSIONID`），可设 `CODE_COOKIE` 环境变量

| 用途 | 方法 | 接口 |
| --- | --- | --- |
| PR 列表 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/pull-requests?state=OPEN&at=refs/heads/{branch}` |
| PR 详情 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/pull-requests/{prId}` |
| PR 活动记录 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/pull-requests/{prId}/activities` |
| 文件列表 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/files?at={branch}&limit=1000&start={n}` |
| 文件内容 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/browse/{filePath}?at={branch}&limit=5000` |
| 原始文件 | GET | `/rest/api/1.0/projects/{project}/repos/{repo}/raw/{path}?at={branch}` |

### 3.2 方式二：OpenAPI 网关（适合服务端调用，更稳定）

> cookie 会过期，本平台还是应该用 OpenAPI 的方式更稳定，具体可以查看 7.2
> 

**Base URL**: `https://dev-api.vip.sankuai.com/mcode`**认证**: 双层鉴权

1. **Oceanus-HTTP 服务认证**（防未授权调用）：
- `oceanus-auth: <token>`（5 分钟过期，用 KMS key `auth_client_com.sankuai.devtools.gateway.service` 生成）
- `oceanus-remote-appkey: com.sankuai.devtools.gateway.service`
1. **STS 权限校验**（验证操作权限）：
- `STS-TOKEN: <token>`（5 分钟过期）
- SSO 方式：用户 MIS + SSO_ID → `SSOTicket`
- IAM 方式：IAM 账号密码 → `IAMTicket`（从 `https://iam.sankuai.com/applied-account` 申请，1 年有效期）

> API 路径格式：`/rest/api/2.0/xxx`（注意是 **2.0**，不是 1.0）
Yapi 文档：`http://yapi.sankuai.com/project/20899/interface/api`
Node.js 接入指南：[km.sankuai.com/collabpage/2131390574](https://km.sankuai.com/collabpage/2131390574)
> 

### 3.3 字段映射

| Dashboard 字段 | 数据来源 |
| --- | --- |
| `prUrl` | PR 详情 → `links.self[0].href` |
| `crMembers` | PR 详情 → `reviewers[].user.name` |
| `crOpenCount` | PR 列表（`state=OPEN`）→ 数量 |
| `crItems` | PR activities（`type=COMMENT`）→ 评论列表 |
| `crStatusDistribution` | PR activities → 需自建统计逻辑 |

### 3.4 数据链路

```
// 代码块
ONES 需求 ID
  → GET /api/1.0/ones/branch/issue/{issueId}        （获取关联分支名）
  → 解析分支名中的 project/repo
  → GET .../pull-requests?state=ALL&at=refs/heads/{branch}  （获取 PR 列表）
  → GET .../pull-requests/{prId}                      （获取 PR 详情 → crMembers, prUrl）
  → GET .../pull-requests/{prId}/activities            （获取活动记录 → crItems）
```

### 四、Ocean 埋点平台（[ocean.sankuai.com](http://ocean.sankuai.com/)）接口

Ocean 是美团统一的埋点管理平台。以下 REST API 端点从 `@datafe/ocean-cli` 源码中反查得到。

**Base URL**: `https://ocean.sankuai.com`**认证**: SSO `access-token` header（通过 `ocean sso login` 获取，3 天有效）
**请求头**:

```
// 代码块
access-token: <sso_token>
Accept: application/json, text/plain, */*
Content-Type: application/json
x-locale: zh
x-requested-with: XMLHttpRequest
```

**响应格式**: `{ "code": 0, "message": "...", "data": { ... } }`（code=0 成功，-100 未认证）

### 4.4 关键发现：Ocean 只管理配置，不存储指标数值

> **⚠️ 重要**：Ocean 平台管理埋点的**配置信息**（名称、cid/bid、负责人、状态等），但**不存储** mc/mv/pv 的实际数值。
实际的指标数值（PV、UV、点击量、曝光量等）存储在**数据仓库的 PV/MV 表**中，需要通过：
> 
> - 各业务线数据仓库 SQL 查询
> - 魔数报表平台（[bi.sankuai.com](http://bi.sankuai.com/)）
> - 产品工具（如灵犀产品）查看
> 参考文档：[04 数据流量的获取和分析](https://km.sankuai.com/collabpage/441983277)

| --- | --- | --- |

| `benefit.indicators` | **数据仓库** | 曝光量、点击量等需 SQL 查询 |

### 7.2 devtools code

三 中说明了有 cookie 和 openAPI 两种方式，考虑到 cookie 的时限性目前选择后者实现

查询文档：

- [1499185696 - DevTools OpenApi 用户手册](https://km.sankuai.com/collabpage/1499185696)
- [2131390574 - OpenAPI: DevTools CodeAPI NodeJS 接入指南](https://km.sankuai.com/collabpage/2131390574)
- [1368011459 - DevTools OpenApi 使用FAQ](https://km.sankuai.com/collabpage/1368011459)
- [1280163608 - DevTools Code API 使用介绍](https://km.sankuai.com/collabpage/1280163608)
- [1221270332 - 1、ssoid换STS Token](https://km.sankuai.com/collabpage/1221270332)
- [1230540993 - 2、IAM账户密码换STS Token](https://km.sankuai.com/collabpage/1230540993)

得到结论：

- DevTools Code OpenAPI 不是单 token，而是双鉴权。
- 请求必须同时带 3 个 header：
    - oceanus-auth
    - oceanus-remote-appkey: com.sankuai.devtools.gateway.service
    - STS-TOKEN
- oceanus-auth 和 STS-TOKEN 都只有 5 分钟左右有效期。
- 线上域名是 [https://dev-api.vip.sankuai.com/mcode](https://dev-api.vip.sankuai.com/mcode)
- 路径要走 /rest/api/2.0/...

有两种拿到 STS-TOKEN 的方式

1. SSO 路线
文档 [1221270332](https://km.sankuai.com/collabpage/1221270332) 说明：
- clientId 用 misId
- 扩展字段里要带 ssoid
- 常见报错 respCode:30002, ssoid 不存在，本质就是 ssoid 不对、环境不对或过期了
1. IAM 路线
文档 [1230540993](https://km.sankuai.com/collabpage/1230540993) 说明：
- clientId 用 IAM 账号
- 扩展字段里要带 iampwd
- NodeJS 接入指南 [2131390574](https://km.sankuai.com/collabpage/2131390574) 明确说，对 MCP/CLI 这类接入，IAM 更合适、更稳定

如果走 IAM 的话得去 [https://iam.sankuai.com/applied-account](https://iam.sankuai.com/applied-account) 申请 IAM 账号

所以先尝试 SSO

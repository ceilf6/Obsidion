### 一、 **项目概述**

### **1.1 项目简介**

```
- ka-mop-poi-select 是秒提业务线下的门店选择页面，日均 PV 80w，基于 Max 跨端技术框架开发，支持 MRN（移动端）、Web 和微信小程序等多端运行。该页面为用户提供基于地理位置的门店搜索、选择功能，是秒提在线点餐和自助核销业务的重要入口。
- ka-mop-city-list-select 是秒提业务线下的城市选择页面，日均 PV 3.8W，该页面为用户提供城市列表展示、搜索和选择功能。
```

### 四、 **多页面事件通信**

由于门店选择页属于承上启下的页面，它的动作需要通过事件告知其他页面，以便其他页面进行门店切换。
#### 4.1  **门店选择页 → 首页/新自核页**

场景：用户在门店选择页切换门店后，通知首页（前置页）刷新货架数据。
页面参数识别：isFromResult = 'true'
```bash
┌──────────────┐
│ 门店选择页    │
└──────┬───────┘
       │ 1. 用户点击门店
       │ 2. publish(KA_MOP_HOME_SWITCH_SHOP) 首页切换门店
       │ 3. publish(KA_MOP_SHOPPING_CART_CLOSE) 通知关闭购物车
       ▼
┌──────────────┐
│    首页       │
│              │
│ - 刷新货架    │
│ - 更新门店    │

```

### **4.4 鸿蒙容器兼容性**

鸿蒙容器下需要使用 KNBProxyToMSI 而非原生 KNB：

```jsx
if (isWebInHarmonyOS()) {
  KNBProxyToMSI.subscribe({
    action: PAGE_EVENT_NAME.KA_MOP_CITY_LIST_SELECTED,
    handle: handleCitySelected,
    success: () => {},
    fail: () => null,
  });
} else {
  subscribeEvent(PAGE_EVENT_NAME.KA_MOP_CITY_LIST_SELECTED, handleCitySelected);
}
```

### 8.1.5 选择性订阅

通过 `pickEquals` 函数实现选择性订阅，减少不必要的渲染：

```tsx
export function pickEquals(pickKeys: string[]) {
  return (pre, next) => {
    const keysA = Object.keys(pre);
    let equals = true;
    for (let i = 0; i < keysA.length; i++) {
      const key = keysA[i];
      if (pickKeys?.includes(key)) {
        equals = shallowEqual(pre[key], next[key]);
      } else {
        equals = pre[key] === next[key];
      }
      if (!equals) {
        break;
      }
    }
    return equals;
  };
}
```

### 8.1.6 批量更新

使用 `batch` 批量更新状态，减少渲染次数：

```tsx
export const useReduxBatchDispatch = () => {
  const dispatchQueue = useRef<Array<() => void>>([]);

  return useRef<{ enqueue: (cb: () => void) => void; dispatch: () => void }>({
    enqueue: (cb: () => void) => {
      dispatchQueue.current.push(cb);
    },
    dispatch: () => {
      batch(() => {
        while (dispatchQueue.current?.length > 0) {
          const func = dispatchQueue.current.shift();
          func?.();
        }
      });
    },
  }).current;
};
```

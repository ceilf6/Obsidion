## 2. 反演规则

即摩根定理

本质是通过反变换去掉取反号，得到的函数是原函数的反函数，逻辑值完全相反

反变换: 取反号下 +  ↔  *  ，然后去掉取反号、给原先取反号下每个元素上取反号、然后加括号（外推时保持优先级）

作变换后得到的函数即原函数的反函数

对于反变量以外的长非号应该保留

## 逻辑函数的不同逻辑表达式

对于一个逻辑函数，其表达式不是唯一的，但是最小项表达式和最大项表达式是唯一的

最小项: 包含n个自变量的与项中每种自变量仅出现一次

最小项编号：可以让自变量按顺序排序，原变量用 1 ，反变量用 0 ，表示十进制

最小项性质：

- 只有一组变量取值使最小项的值为 1 ，且此时其余取值均使其为 0
- 对于一个式子中不同的最小项，使得其值为 1 的那一组变量取值也不同
- 所以同一组取值的最小项的任意两个乘积为 0，全体和为 1

最大项: 包含n个自变量的或项中每个自变量以原变量和反变量形式都出现一次且仅出现一次

最大项性质：

- 只有一组变量取值使最大项的值为0，且此时其余取值均为1
- 任意两个最大项和为1
- 全体最大项积为0

最大项和最小项之间有对偶性

### 全加器

本质是求每个权上的值

因为在多位二进制加法中（比如加法器的每一位）：

- 我们要相加当前的两个二进制位 **A** 和 **B**；
- 还要把低位产生的**进位 CinC_{in}Cin** 加上来。

所以，全加器的输入是三个信号：

- AAA：加数位
- BBB：被加数位
- CinC_{in}Cin：来自低位的进位

输出是两个信号：

- SSS：该位的**和**
- CoutC_{out}Cout：向高位的**进位**

## 🧮 一、什么是 2 位并行加法器

> 2 位并行加法器是能同时完成两个 2 位二进制数相加的组合逻辑电路。
> 
> 
> 它由 **两个全加器（Full Adder）级联** 实现。
> 

例如：

要相加两个二进制数

[

A_1 A_0 + B_1 B_0

]

（下标 0 表示低位，1 表示高位）

---

## ⚙️ 二、输入与输出

| 名称 | 含义 |
| --- | --- |
| A₁, A₀ | 被加数的高位和低位 |
| B₁, B₀ | 加数的高位和低位 |
| C₀ | 输入进位（通常为0） |
| S₁, S₀ | 结果的高位和低位的和输出 |
| C₂ | 最后的进位输出 |

---

## 🧩 三、工作原理

整个 2 位加法器由 **两个全加器** 组成：

### 第一个全加器（低位）：

- 输入：A₀, B₀, C₀
- 输出：S₀, C₁（进位到下一位）

[

S_0 = A_0 \oplus B_0 \oplus C_0

]

[

C_1 = A_0B_0 + A_0C_0 + B_0C_0

]

---

### 第二个全加器（高位）：

- 输入：A₁, B₁, C₁（来自低位的进位）
- 输出：S₁, C₂（最终进位输出）

[

S_1 = A_1 \oplus B_1 \oplus C_1

]

[

C_2 = A_1B_1 + A_1C_1 + B_1C_1

]

---

## 🔗 四、逻辑连接关系图（文字结构）

```
         ┌──────────────┐
A0 ─────▶│              │
B0 ─────▶│ 全加器1      │──▶ S0
C0 ─────▶│（低位）       │
         │              │──▶ C1 ─────┐
         └──────────────┘            │
                                     ▼
                             ┌──────────────┐
A1 ─────────────────────────▶│              │
B1 ─────────────────────────▶│ 全加器2      │──▶ S1
C1 ─────────────────────────▶│（高位）       │
                             │              │──▶ C2（最终进位）
                             └──────────────┘

```

## 🧠 五、举个例子

设：

[

A_1A_0 = 10_2 = 2_{10}

]

[

B_1B_0 = 11_2 = 3_{10}

]

[

C_0 = 0

]

那么：

- 低位加法： 0 + 1 + 0 = 1 → S₀ = 1，C₁ = 0
- 高位加法： 1 + 1 + 0 = 10 → S₁ = 0，C₂ = 1

结果：

[

C_2 S_1 S_0 = 101_2 = 5_{10}

]

✅ 正确！

## 💡 七、推广

- **4位并行加法器**：用4个全加器串联。
- **n位并行加法器**：由n个全加器组成。
    
    每个全加器的进位输出连接到下一个全加器的进位输入。

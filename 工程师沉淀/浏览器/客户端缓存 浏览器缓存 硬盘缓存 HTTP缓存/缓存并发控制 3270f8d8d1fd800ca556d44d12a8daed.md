# 锁高速缓存

本质：同一时间只允许一个线程去 重建缓存，其他线程等待或走降级逻辑

重建缓存：当缓存失效时，重新从数据源拿数据然后写入缓存

```tsx
请求 → 查询缓存
   ↓
未命中
   ↓
尝试获取锁
   ↓
成功 → 查询数据库 → 写缓存 → 释放锁
失败 → 等待 / 重试 / 返回旧数据
```

当数据主要被各个客户端“各自使用”时，可以把锁也缓存到客户端，从而减少频繁和服务器通信；但如果其他客户端需要这个数据，服务器必须把之前发出去的锁收回来。

锁降级就是通过数据服务器向客户端发送对锁进行降级的请求而启动，并且客户端通过获取粒度更细的锁，再释放粒度更粗的锁进行响应

# 跨页面通信

A页面操作后，B页面要实时响应，例如权限变更等等

一种是通过每次操作都得走过 鉴权守卫、校验token

还有一种就是通过跨页面通信

1. localStorage
    
    [浏览器规定：当一个页面修改 localStorage 时，其他页面会触发 storage 事件](跨页面通信%2031a0f8d8d1fd8020926dd7ef30a2f0fe.md) 
    

1. **通道 BroadcastChannel** 专门用于多页面通信的API
    
    **发布订阅模式**
    
    和 MessageChannel 一样、都是浏览器提供的跨上下文通信API，底层都是消息机制，MessageChannel是 1对1，BroadcastChannel是广播 1对多
    
    传播 通道
    
    ```jsx
    const channel = new BroadcastChannel('auth')
    ```
    
    ```jsx
    channel.postMessage({
      type: 'logout'
    })
    ```
    
    ```jsx
    channel.onmessage = (event) => {
      if (event.data.type === 'logout') {
        location.href = '/login'
      }
    }
    ```
    

1. 多页面共享一个 **SharedWorker**
    
    SharedWorker 类似于 BroadcastChannel 的拓展版，不仅支持跨tab页广播，还能共享计算、共享缓存
    

1. 如果是 PWA架构，可以用 Service Worker 向所有页面广播消息
    
    ```jsx
    clients.matchAll()
    ```
    
    [PWA](PWA%2031a0f8d8d1fd80aa8490cadeb4d879d1.md)

# 层叠 - 优先级

声明冲突：同一个样式（属性），多次应用到同一个元素

层叠：解决声明冲突的过程，浏览器自动处理（权重计算）

最终一个样式属性只能有一个幸存值

## 1. 比较重要性

重要性从高到低

1. 作者（开发者）样式表中的 **!important** 声明
2. 作者样式表中的普通样式
3. 浏览器默认样式表

> 如果重要性已经胜出了就没必要比较后面的了
> 

## 2. 比较特殊性 - 看选择器

总体规则：选择器选中的范围越窄越特殊

具体规则：通过选择器，计算出一个四位数 xxxx

1. 千位：如果是 **内联样式** ，记1，否则记0（内联样式：直接在开始标签中写属性 style）
2. 百位：等于选择器中所有 **id选择器** 的数量
3. 十位：等于选择器中所有 **类选择器**、**属性选择器**、**伪类选择器** 的数量
4. 个位：等于选择器中所有 **元素选择器**、**伪元素选择器** 的数量

注意这几位数是分开存储互不影响的，所以不存在进位的情况

## 3. 比较源次序

代码书写靠后的胜出

## 应用

1. 重置样式表
    
    书写一些作者样式，覆盖浏览器的默认样式（防止不同浏览器样式不同）
    例如一般写一个通用覆盖 reset.css（常见的网上有 meyer.css, normalize.css）
    然后再开一个 myStyle.css
    
2. 爱恨法则
link > visited > hover > active
在某些时候会多个样式应用，又因为重要性和特殊性相同，所以就得通过源次序让 a 展示的效果符合要求
那么就是
点击 > 悬停 > 访问过 > 普通未访问
越重要的越靠后

# web字体和图标

## web字体

解决用户电脑上没有安装相应字体的问题

当用户电脑上没有安装相应字体时，强制让用户下载该字体

使用 @font-face 制作一个新字体

font-family: 取名字

src: url(” .ttf”) 文件路径

## 字体图标

iconfont.cn

选择图标 添加至购物车，然后在购物车中添加到项目，然后在项目中点击在线链接，能得到一个域名

这个域名就是一个 字体图标 CSS 文件

每次更新都需要更新域名

或者直接下载离线使用

无论哪种都是使用字体

1. unicode 直接 & 以**实体字符**形式插入
2. font class 以类名形式插入

# 定位练习

# 1. 二级菜单

```css
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}

.header {
    background-color: #1A1B27;
    color: #bf91f3;

    height: 40px;
    line-height: 40px;
    /* 单行文本水平居中 */

    position: fixed;
    top: 0;
    width: 100%;
    /* 注意宽度必须设置 100% 否则该绝对定位盒子就是适应内容的宽度 */

    left: 0;
    right: 0;
    margin: 0 auto;
}

.header .top-nav>li {
    float: left;
    margin: 0 15px;
    padding: 0 8px;

    /* 得设置宽度，不然 浮动宽度auto会被撑开 */
    width: 140px;

    text-align: center;

    height: 40px;

    /* 为了防止 hover 时 边框出现导致的变化 */
    box-sizing: border-box;

    /* 作为坐标系 */
    position: relative;
}

/* 移动到菜单上时 上、左、右 会出现边框 */
.header .top-nav>li:hover {
    background-color: lightblue;

    border: 2px solid #bf91f3;
    border-bottom: none;

    /* 为了防止 hover 时 边框出现导致的变化 
    40px - 2px
    */
    line-height: 38px;
}

.header .top-nav>li>.submenu {
    line-height: 1.5;
    width: 300px;

    text-align: left;
    background-color: lightblue;

    /* 不生成盒子 */
    display: none;

    border: 2px solid #bf91f3;
    box-sizing: border-box;
    /* border-top: none; */
    /*
    处理二者衔接处的 border：
    1. 再写一个元素直接覆盖
    2. 通过伪元素 :)
    */

    /* 通过绝对定位精准衔接
    注意上边还有 2px 的 border
    */
    position: absolute;
    right: -2px;
}

/* 注意得是共同的父元素，即li */
.header .top-nav>li:hover .submenu {
    display: block;
}

.header .top-nav>li:hover::after {
    content: "";
    /* 注意：伪元素必须有内容才会出现 */

    position: absolute;

    bottom: -2px;
    /* 注意！一定要改为负值，向下延伸 2px 覆盖 border */

    left: 0;

    width: 100%;
    height: 5px;

    background-color: lightblue;
}
```

```css
  对于 position: fixed 或 position: absolute 的元素，单独使用 margin: 0 auto 不会生效，因为这些定位元素脱离了正常文档流。     
                                                                                                                              
  要让固定定位元素居中，需要配合 left 和 right 属性：                                                                         
                                                                                                                              
  .header {                                                                                                                   
      position: fixed;                                                                                                        
      top: 0;                                                                                                                 
      left: 0;      /* 添加这行 */                                                                                            
      right: 0;     /* 添加这行 */                                                                                            
      width: 100%;                                                                                                            
      margin: 0 auto;                                                                                                         
      /* ... 其他样式 */                                                                                                      
  }                                                                                                                           
                                                                                                                              
  原理： left: 0; right: 0; 让元素从左到右拉伸，再配合 margin: 0 auto 和固定宽度才能实现居中。                                
                                                                                                                              
  不过在你的情况下，因为已经设置了 width:                                                                                     
  100%，元素本身就占满了整个视口宽度，所以实际上不需要"居中"（已经是全宽了）。如果你是想让 header 有固定宽度并居中，应该这样：
                                                                                                                              
  .header {                                                                                                                   
      position: fixed;                                                                                                        
      top: 0;                                                                                                                 
      left: 0;                                                                                                                
      right: 0;                                                                                                               
      width: 1200px;  /* 固定宽度，而不是 100% */                                                                             
      margin: 0 auto;                                                                                                         
      /* ... */                                                                                                               
  }
```

```css
  问题在于：伪元素的位置不对。                                                                                                
                                                                                                                              
  当前伪元素设置 bottom: 0，意味着它在 li 元素的底部边缘内部。但是 submenu 的 border-top 是在 li 底部边缘外部（因为 submenu   
  是绝对定位，紧贴在 li 下方）。                                                                                              
                                                                                                                              
  解决方法是让伪元素向下延伸，覆盖到 submenu 的 border 区域：                                                                 
                                                                                                                              
  .header .top-nav>li:hover::after {                                                                                          
      content: "";                                                                                                            
      position: absolute;                                                                                                     
      bottom: -2px;  /* 改为负值，向下延伸 2px 覆盖 border */                                                                 
      left: 0;                                                                                                                
      width: 100%;                                                                                                            
      height: 5px;                                                                                                            
      background-color: lightblue;                                                                                            
      z-index: 1;                                                                                                             
  }                                                                                                                           
                                                                                                                              
  关键修改：                                                                                                                  
  - bottom: -2px - 让伪元素向下移动 2px，正好覆盖 submenu 的 2px border-top                                                   
  - z-index: 1 - 确保伪元素在 submenu 之上                                                                                    
                                                                                                                              
  这样伪元素就会从 li 底部向下延伸，遮挡住二级菜单的上边框，制造出一级菜单和二级菜单"连在一起"的视觉效果。  
  
  
  ！下面的分析无关
  
  
  问题在于 层叠顺序（z-index）。虽然伪元素 ::after 和 .submenu 都是绝对定位，但 .submenu 作为 li 的子元素，在没有设置 z-index 
  的情况下，会自然地显示在父元素的伪元素之上。                                                                                
                                                                                                                              
  简单来说：子元素（submenu）默认会覆盖在父元素的伪元素（::after）之上。                                                      
                                                                                                                              
  解决方法是给伪元素添加 z-index，让它提升到 submenu 之上：                                                                   
                                                                                                                              
  .header .top-nav>li:hover::after {                                                                                          
      content: "";                                                                                                            
      position: absolute;                                                                                                     
      bottom: 0;                                                                                                              
      left: 0;                                                                                                                
      width: 100%;                                                                                                            
      height: 5px;                                                                                                            
      background-color: lightblue;                                                                                            
      z-index: 1;  /* 添加这一行 */                                                                                           
  }                                                                                                                           
                                                                                                                              
  这样伪元素就能成功遮挡住二级菜单的 border-top 了。                                                                          
                                                                                                                              
  CSS 层叠规则说明：                                                                                                          
  - 当两个定位元素没有设置 z-index 时，子元素会渲染在父元素的伪元素之上                                                       
  - 通过设置 z-index: 1，伪元素会提升到更高的层叠层级，从而覆盖 submenu 的边框
```

# 2. 弹出层

## 居中

1. 通过 margin 获取剩余空间
2. 在中心居中后通过 transform 拉回一半
3. flex 通过 justify-content 和 align-items
4. grid

```css
.main img {
    width: 100%;
}

/* 遮蒙层 */
.modal {
    position: fixed;
    width: 100%;
    height: 100%;

    top: 0;
    left: 0;

    /* 半透明 - 一般都是黑色 */
    background-color: rgba(0, 0, 0, .5);
}

/* 蒙层内部的居中 */
/* 
1. 通过 margin 获取剩余空间
    .modal .container {
    position: absolute;

    width: 400px;
    height: 512px;

    left: 0;
    right: 0;
    top: 0;
    bottom: 0;
    margin: auto;
} */

/* 
2. 在中心居中后通过 transform 拉回一般
    .modal .container {
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
} */

/* 3. flex 通过 justify-content 和 align-items */
.modal {
    position: fixed;
    inset: 0;
    background-color: rgba(0, 0, 0, .5);

    display: flex;
    justify-content: center;
    align-items: center;
}

/* 4. grid */
.modal {
    position: fixed;
    inset: 0;
    background: rgba(0, 0, 0, .5);

    display: grid;
    place-items: center;
}
```

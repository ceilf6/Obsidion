4. 函数包裹
    
    每个CMJ模块都有能力
    
    - exports
    - require
    - module
    - __filename
    - __dirname
    
    正是因为每个CMJ都会被函数包裹，将这些能力作为**参数传入**
    
5. 创建 module 对象
    
    ```tsx
      module.exports = {};
      const exports = module.exports;
    ```
    
    调用 .call 函数，其中 **this** 就是 **module.exports** 对象
    
    this === exports === module.exports
    
    返回对象

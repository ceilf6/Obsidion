# Webhook

Webhook（中文通常称作“网络钩子”）是一种在网络应用中实现实时通信的机制。它的核心概念是：当某个事件发生时，系统会自动向你指定的 URL 发送一个 HTTP 请求，从而通知你或触发后续操作。简单来说，它是一种“被动推送”的方式，让你的系统可以即时接收到外部系统的消息，而不是主动去轮询（polling）对方。

### Webhook 的工作原理

1. **注册 Webhook**：你在应用 A 中注册一个 Webhook URL（例如 `https://yourserver.com/webhook`），并指定希望监听的事件（比如“用户下单”或“文件上传完成”）。
2. **事件触发**：当指定事件在应用 A 中发生时，应用 A 会向你注册的 URL 发送一个 HTTP 请求（通常是 POST 请求），并带上事件数据（通常是 JSON 格式）。
3. **处理请求**：你的服务器接收到请求后，解析数据并执行相应操作，比如更新数据库、发送通知、调用其他 API 等。
4. **响应确认**：你的服务器通常需要返回 HTTP 状态码（比如 200 OK），告诉发送方已经成功接收事件。

### Webhook 的优点

- **实时性**：事件发生即可触发，无需轮询。
- **高效性**：只在事件发生时才发送请求，节省资源。
- **易于扩展**：可以将事件通知多个系统或服务。

### 常见应用场景

- 支付平台（如 Stripe、PayPal）发送付款成功通知。
- Git 服务（如 GitHub、GitLab）在代码 push 或 PR 时通知 CI/CD 系统。
- 消息平台（如 Slack、Discord）接收外部系统消息并推送到聊天频道。
- 电商或 SaaS 系统中的订单、库存、用户行为实时同步。

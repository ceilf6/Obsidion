# 事件总线 发布订阅模式

# 功能

1. 提供监听某个事件的接口
2. 提供取消监听的接口
3. 触发事件的接口（可传递数据）
4. 触发事件后会自动通知监听者

事件总线方便了组件之间、甚至组件和普通JS模块之间的通信

![image.png](工程师沉淀/Vue/Vue2/事件总线%20发布订阅模式/image.png)

本质是**发布订阅模式**

事件总线监听着组件

当触发事件时，组件就可以往事件总线上抛事件相关的数据

事件总线会将这些数据传递给所有监听该事件的监听者，让他们运行

当组件卸载时，事件总线会直接将监听器移除

# 实现

```jsx
// 观察者列表
// 事件: [回调函数] 如 { "event1": Set(handler1,handler2) }
const listeners = {};

export default {
    // 监听某一个事件
    $on(eventName, handler) {
        if (!listeners[eventName]) listeners[eventName] = new Set(); // 内部通过 Set 防止重复
        listeners[eventName].add(handler)
    },
    // 取消 handler 对 eventName 事件的监听
    $off(eventName, handler) {
        if (!listeners[eventName]) return
        listeners[eventName].delete(handler)
    },
    // 触发事件
    $emit(eventName, ...args) { // 往事件总线上抛事件相关的数据
        if (!listeners[eventName]) return
        for (const handler of listeners[eventName]) handler(...args)
    }
}
```

```jsx
// 因为 Vue 实例自带 $emit, $on, $off 实例成员(只有Vue实例有，Vue构造函数是没有的)
// 直接导出一个 Vue 实例即可
import Vue from "vue";
const eventBus = new Vue({});
Vue.prototype.$bus = eventBus; // 挂到Vue构造函数原型上，让所有组件实例都能通过 this.$bus 访问同一个事件总线
export default eventBus;
```

# 实践

mixins/mainScroll 滚动事件

```jsx
export default function (refValue) {
    return {
        mounted() {
            this.$bus.$on("setMainScroll", this.handleSetMainScroll);
            this.$refs[refValue].addEventListener("scroll", this.handleMainScroll);
        },
        beforeDestroy() {
            this.$bus.$emit("mainScroll");
            this.$bus.$off("setMainScroll", this.handleSetMainScroll);
            this.$refs[refValue].removeEventListener("scroll", this.handleMainScroll);
        },
        methods: {
            handleSetMainScroll(scrollTop) {
                this.$refs[refValue].scrollTop = scrollTop;
            },
            handleMainScroll() {
                this.$bus.$emit("mainScroll", this.$refs[refValue]);
            },
        },
    };
}
```

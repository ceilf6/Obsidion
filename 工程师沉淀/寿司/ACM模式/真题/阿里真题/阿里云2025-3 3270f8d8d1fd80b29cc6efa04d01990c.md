一个数在**最终乘积**里贡献多少个二进制末尾 0，本质上就是：

> 它能给整个乘积提供多少个**因子 2**
> 

能操作两次，有两种可能：1+1 或 2

```jsx
function v2(x) {
    let cnt = 0;
    while ((x & 1) === 0) { 
    // 还没碰到x二进制末尾的1
        cnt++;
        x >>= 1;
    }
    return cnt;
}
```

    const n = Number(await readline());
    const a = (await readline()).split(' ').map(Number);

    let base = 0;

    let best1 = 0;   // 最大的 gain1
    let best2 = 0;   // 第二大的 gain1
    let bestGain2 = 0; // 最大的 gain2

    for (const x of a) {
        const cur = v2(x);
        base += cur;

        const g1 = v2(x + 1) - cur;
        const g2 = v2(x + 2) - cur;

        if (g1 > best1) {
            best2 = best1;
            best1 = g1;
        } else if (g1 > best2) {
            best2 = g1;
        }

        if (g2 > bestGain2) bestGain2 = g2;
    }

    const ans = base + Math.max(0, bestGain2, best1 + best2);

从任意点出发BFS找最远点A，点A一定是某条直径的端点

然后再从A点BFS找A点的最远点

```jsx
    // 两次BFS
    let queue = []
    let head = 0
    let vis = new Array(n).fill(0)
    let farNode;
    let maxD = -Infinity;
    function BFS(i){
        vis[i] = 1
        queue.push([i,0])
        while(head < queue.length){
            // shift 会整体移动数组性能过差
            const [cur,curD] = queue[head]
            head++
            // const [cur,curD] = queue.shift()
            let flag = 0 // 是否能往下走，即是否到头了
            for(const nxt of next[cur]){
                if(!vis[nxt]){
                    vis[nxt] = 1
                    queue.push([nxt,curD+1])
                    flag=1
                }
            }
            if(!flag && maxD < curD){
                // 注意一定要比较得到是最远的
                farNode = cur
                maxD = curD
            }
        }
    }
    BFS(0)
    // 刷新
    // queue = []
    vis = new Array(n).fill(0)
    BFS(farNode)
```

# 缓冲技术

有 n 块

若每块有三步：

- 输入：T
- 送用户区：M
- CPU处理：C

### **单缓冲**

$$

T+M+C+(n-1)\times (M+\max(T,C))
$$

### **双缓冲**

$$

T+M+C+(n-1)\times \max(T,M,C)
$$

# 二叉搜索树 BST

一颗有有序性的二叉树

对于树中任意一个节点 x

- 左子树中所有节点值都小于 x
- 右子树中所有节点值都大于 x

查询效率高，类似于二分查找每次比较都可以排除一半的子树

```python
Search(root, key):
    if root == null:
        return null
    if key == root.val:
        return root
    else if key < root.val:
        return Search(root.left, key)
    else:
        return Search(root.right, key)
```

查询平均效率是 O(log n) 

最坏退化成链表时 O(n)

中序遍历 左根右 一定是从小到大有序的

插入是从根一直往下比

删除：找 中序后继 或 中序前驱 进行替换

前驱：比其小的最大值；后继：比其大的最小值

“二叉搜索树的查找、插入和删除操作的时间复杂度都是O(log n)，其中n是二叉树的节点数。”

❌ 因为 O(logn) 是平均值，最坏可以达到 O(n)

# 操作系统优先级调度

- 优先级调度可能导致低优先级进程的饥饿，因为高优先级进程会不断插入执行。
- 优先级调度依赖于**进程的优先级**，而不是执行时间。
- 优先级调度可以是抢占式或非抢占式。
- **老化技术**可以**逐渐提高等待时间长的进程的优先级，避免饥饿**。

# 线程和进程

- **线程共享进程的地址空间**，因此可以**访问相同的全局变量和堆内存**。
- **进程之间不能直接共享内存**，必须通过进程间**通信**机制（如共享内存、消息传递）来实现。
- **每个线程有自己的堆栈和寄存器状态**，但共享进程的其他资源。
- 进程切换的开销通常大于线程切换，因为进程切换涉及更多的上下文信息（如地址空间切换）。

# 数据库 - 事务幻读

在事务的隔离级别中，幻读（Phantom Read）是指一个事务在多次读取同一范围的数据时，由于其他事务在该范围内插入新数据，导致后续读取出现额外行的现象。以下是各隔离级别的分析：

### 选项分析：

- **A. 可重复读（REPEATABLE READ）**
    
    **可避免幻读**。在可重复读隔离级别下，MySQL 的 InnoDB 引擎通过 **间隙锁（Gap Lock）** 和 **临键锁（Next-Key Lock）** 机制锁定查询范围，阻止其他事务在范围内插入新数据，从而有效避免幻读。虽然 SQL 标准中该级别不要求避免幻读，但 MySQL 的实现实际做到了这一点。
    
- **B. 读已提交（READ COMMITTED）**
    
    **无法避免幻读**。该级别仅能避免脏读，但允许其他事务在查询范围内插入新数据。例如：事务 A 第一次查询得到 5 条数据，事务 B 插入一条新数据后提交，事务 A 再次查询可能得到 6 条数据。
    
- **C. 串行化（SERIALIZABLE）**
    
    **可避免幻读**。这是最高的隔离级别，通过强制事务串行执行（类似于加表级锁），完全阻止并发修改，因此能避免脏读、不可重复读和幻读。
    
- **D. 读未提交（READ UNCOMMITTED）**
    
    **无法避免幻读**。最低的隔离级别，允许读取未提交的数据，无法避免脏读、不可重复读和幻读。
    

### 正确答案：

能有效避免幻读的隔离级别是：

**A. 可重复读（REPEATABLE READ）** 和 **C. 串行化（SERIALIZABLE）**。

### 总结：

- **可重复读（REPEATABLE READ）**：通过间隙锁/临键锁避免幻读（MySQL 实现）。
- **串行化（SERIALIZABLE）**：通过强制串行化避免幻读。其他级别（读已提交、读未提交）均无法避免幻读。

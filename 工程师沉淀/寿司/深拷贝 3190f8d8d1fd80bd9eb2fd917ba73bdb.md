# 深拷贝

用**记忆化**解决循环引用问题：如果某个对象已经拷贝过了，就直接返回之前的拷贝
映射: 原对象 -> 拷贝对象

而用 WeakMap 而不是 Map 实现映射的原因是，WeakMap 是**弱引用**，不会阻止GC，而Map强引用会导致原对象无法GC，内存泄漏

```jsx
function deepCopy(from, memo = new WeakMap()) {
    if (typeof from !== 'object' || from === null) {
        return from
    }

    if (memo.has(from)) {
        return memo.get(from)
    }

    let to

    if (from instanceof Date) {
        to = new Date(from)
    }
    else if (from instanceof RegExp) {
        to = new RegExp(from)
    }
    // 下面的对象类型就需要递归来实现深度拷贝
    else if (from instanceof Map) {
        to = new Map()
        memo.set(from, to)
        from.forEach((v, k) => {
		        // 注意 键 和 值 都需要深拷贝
            to.set(deepCopy(k, memo), deepCopy(v, memo))
        })
        return to
    }
    else if (from instanceof Set) {
        to = new Set()
        memo.set(from, to)
        from.forEach(v => {
            to.add(deepCopy(v, memo))
        })
        return to
    }
    else {
        to = Array.isArray(from) ? [] : {}
    }

    memo.set(from, to)

    for (const key in from) {
        if (from.hasOwnProperty(key)) {
            to[key] = deepCopy(from[key], memo) // 注意得用属性计算符 [] 而不是 .
        }
    }

    return to
}
```

for in 可能会拿到 原型链 上可枚举属性

通过加一层 hasOwnProperty 判断实现只拷贝自身的属性，不拷贝继承来的属性

# 构造函数

> 对象中的属性，如果是一个函数，也称该属性为对象的方法
> 

## 用于创建对象的函数

用函数创建对象，可以减少繁琐的对象创建流程

1. 函数返回一个对象
2. 构造函数：**构造函数专门用于创建对象**

```jsx
new 函数名(参数);
```

如果使用上面的格式即 **new声明** 创建，则必定会返回对象，该函数叫做**构造函数**。

1. 函数名使用大驼峰命名法
2. 构造函数内部，**会自动创建一个新对象**，把这个对象的**隐式原型prototype指向构造函数的原型**，**this指向新创建的对象**，并且**自动返回新对象**
3. 构造函数中如果出现返回值，如果**返回的是原始类型，则直接忽略；如果返回的是引用类型，则使用返回的结果**
4. **所有**的**对象，**最终**都是通过构造函数**创建的

```jsx
function CreateObj2(name = 'ceilf5', age = 5) { // 注意是在形参位置设置默认值
    this.name = name;
    this.age = age;

    // 本质是返回一个新对象
    const newObj = new Object();
    newObj.name = name;
    newObj.age = age;
    return newObj;
}
```

## new.target

该表达式**在函数中使用**，返回的是当前的构造函数，但是，如果该函数**不是通过new调用的，则返回undefined**

通常**用于判断某个函数是否是通过new在调用**。

```jsx
    if (new.target) {
        console.log('正确的通过 new 调用')
        console.log(new.target) // [Function: 函数名]
    } else {
        console.log('使用方法错误，应该用 new')
        return
    }
```

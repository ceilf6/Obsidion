**原型上不要挂载箭头函数**

- **所有对象都是通过`new 构造函数`创建**

- 函数的本质就是对象
    
    **函数是通过 new Function 产生的**
    
    ![image.png](%E5%8E%9F%E5%9E%8B%E5%92%8C%E5%8E%9F%E5%9E%8B%E9%93%BE/image%201.png)
    
    - 函数中可以有属性
- 所有对象都是引用类型

## 原型 prototype

所有**函数（特殊的对象）**都有一个属性：**prototype**，称之为函数原型

默认情况下，prototype是一个普通的Object**对象**

默认情况下，prototype中有一个**属性**，**constructor**，它也是一个对象，它**指向构造函数本身**

func.prototype.constructor === func

![image.png](%E5%8E%9F%E5%9E%8B%E5%92%8C%E5%8E%9F%E5%9E%8B%E9%93%BE/image%202.png)

## 隐式原型 __proto**__**

所有的**对象**都有一个属性：`__proto__`，称之为隐式原型

默认情况下，隐式原型**__proto__**指向**创建该对象的构造函数的原型**

同一个构造函数 new 出来的对象**共用同一块内存空间**表示**隐式原型属性**，都是**同一个构造函数的原型**

func.prototype === objs.__proto__

```jsx
// 拿创建obj的构造函数名称
obj.__proto__.constructor.name
// obj.__proto__ === obj构造函数.prototype
// 然后原型取constuctor的 name属性
```

![image.png](%E5%8E%9F%E5%9E%8B%E5%92%8C%E5%8E%9F%E5%9E%8B%E9%93%BE/image%203.png)

```jsx
function Construct() {
    this.notShareFunc = function () { // 每次 new 创建新的函数对象 this 都会跟随
        console.log('I\'m not shared')
    }
}
// func.prototype === objs.__proto__
Construct.prototype.shareFunc = function () {
    console.log('I\'m shared')
}
const obj1 = new Construct();
const obj2 = new Construct();
console.log('obj1.notShareFunc == obj2.notShareFunc', obj1.notShareFunc == obj2.notShareFunc)
// false
console.log('obj1.shareFunc == obj2.shareFunc', obj1.shareFunc == obj2.shareFunc)
// true
```

当访问一个对象的成员时：

1. 看该对象自身是否拥有该成员，如果有直接使用
2. 在原型链中依次查找是否拥有该成员，如果有直接使用

猴子补丁：在**函数原型**中**加入成员**，以增强起对象的功能，猴子补丁会导致**原型污染**，使用需谨慎。

选课系统脚本中最终并没有选择猴子补丁的方式，因为害怕入侵性强导致系统原先功能出错

```jsx
console.log(func.prototype === Function.prototype); 
// false

console.log(func.__proto__ === Function.prototype); 
// true
// Function.prototype === Function.__proto__
console.log(func.__proto__ === Function.__proto__); 
// true

console.log(Function.__proto__ === Object.__proto__); 
// true
// Object 都是 Funcion 创建的，都指向 Function.prototype
```

# JS判断类型

## 1. **ES5** 规定 Object.prototype.toString 返回

最精准的方法

**JS 对象有内部槽 [[Class]]**
**ES5** 规定 Object.prototype.toString 返回 JS对象**内部槽**

```jsx
`[object ${[[Class]]}]`
```

```jsx
const obj = new Object();
const str = new String();

console.log(obj.toString())
console.log(Object.prototype.toString.call(obj)) 
// [object Object]
console.log(Object.prototype.toString.call(str)) 
// **[object String]**

console.log(str.__proto__.constructor.name); 
// String
// 但是不推荐使用系统成员
```

## 2. typeof

适合判断基本数据类型

```jsx
number
string
boolean
undefined
symbol
bigint
function
```

无法区分引用数据类型，都返回 object

```jsx
object
array
null
date
regexp
```

## 3. instanceof

利用判断是否在原型链上，可以区分引用数据类型

```jsx
[] instanceof Array        // true
[] instanceof Object       // true
new Date() instanceof Date // true
```

[包装类](%E5%87%BD%E6%95%B0%E7%9A%84%E6%9C%AC%E8%B4%A8%E5%B0%B1%E6%98%AF%E5%AF%B9%E8%B1%A1%202fc0f8d8d1fd80d581dece332efeae46.md)

```jsx
1 instanceof Number
```

得到的是 false ，因为是 1 而不是 new Number(1)

# 类中静态函数

类本质是对象

其中静态函数是属于类的，无法通过实例调用

本质就是：

**普通方法（实例方法）**是通过 **实例 → 类.prototype（构造函数的原型对象）** 调用的

```jsx
A**.prototype.**xxx = function(){}
```

**静态方法**是通过 **类本身（构造函数对象）** 调用的

```jsx
A.xxx = function(){}
```

# 原型链的应用

## 基础方法

W3C不推荐直接使用系统成员 __proto__ ，而是暴露了一个 API

### **Object.getPrototypeOf(对象)**

用于获取**对象的隐式原型**

```jsx
Object.**getPrototypeOf**(obj) === obj.__proto__
```

这个函数是在Object函数对象里面，一般对象没有

![image.png](%E5%8E%9F%E5%9E%8B%E5%92%8C%E5%8E%9F%E5%9E%8B%E9%93%BE/image%205.png)

### **构造函数.prototype.isPrototypeOf(对象)**

一般对象也能用

判断当前对象(this)是否在构造函数的原型链上

```jsx
通过原型链判断是否为目标类型

例如数组
// 1. 使用静态方法 Array.isArray()

// 2. 用 原型API 判断目标是否在数组的原型链上
// (1) isPrototypeOf
const target = []; // document.get / query
const bool1 = Array.prototype.isPrototypeOf(target)
console.log(bool1)
```

### **对象 instanceof 函数**

判断**函数的原型**是否在**对象的原型链**上

a 是否为 B

```jsx
// (2) instanceof
const bool2 = target instanceof Array
console.log(bool2)
// 注意如果有iframe跨越了窗口Array会指向不一样
```

### **Object.create(对象a)**

创建一个新对象，其**隐式原型指向指定的对象**a，即**接入对象a的原型链**

“是不是所有对象的原型链最终都是Object原型” 

Object.create(null) 得到的是纯净的对象

![image.png](%E5%8E%9F%E5%9E%8B%E5%92%8C%E5%8E%9F%E5%9E%8B%E9%93%BE/image%206.png)

### **Object.prototype.hasOwnProperty(属性名)**

判断一个对象**自身**是否拥有某个属性

不去原型链上找

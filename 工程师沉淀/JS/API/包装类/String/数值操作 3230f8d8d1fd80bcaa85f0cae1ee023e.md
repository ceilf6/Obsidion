# 数值操作

```tsx
let a = '2026'
let b = a
let c = a

b--
c += 1
console.log(a, b, c) // 2026 2025 20261
```

原始数据类型直接赋值，而不像引用数据类型是复制引用地址，所以不会影响原来值

所以初始值 a,b,c 都是 ‘2026’

## - -

```tsx
b--
```

是数值运算符，会触发**隐式类型转换**

‘2026’ => Number(’2026’) 后 -1

即 2025

## + =

```tsx
c+=1
```

‘2026’ **+** 1 **加法中有字符串的话直接 字符串拼接**

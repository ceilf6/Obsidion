filter 不会改变原数组

**slice 不会影响原数组，splice 会**

通过**维护head变量**避开 **.shift()的严重性能损耗**（shift会平移整个数组）

[](阿里云2025-3%203270f8d8d1fd80b29cc6efa04d01990c.md) 中对 BFS 用 head 维护队列头

shift() 是从左边出去，**unshift() 就是从左边插入**

**in** 判断的是下标是否存在

判断值是否存在得用 **.includes**

```jsx
console.log(6 in [6]) // false
console.log(0 in [6]) // true

console.log([6].includes(6)) // true
```

# BigInt

对大数处理常见的方法

1. 转为数组
2. BigInt

JS的普通Number是基于 IEEE 754 双精度浮点数，只能安全表示到 2**53 - 1

BigInt 就不会（但只能表示整数，不能表示小数）

# 创建 BigInt

## 1. 字面量写法 n

直接在整数后面加 n

```jsx
const x = 123n
const y = 9007199254740993123456789n
const z = -42n
```

## 2. 用 BigInt( )

```jsx
const a = BigInt(123)
const b = BigInt("9007199254740993123456789")
const c = BigInt("0xff")
const d = BigInt("0b1010")
const e = BigInt("0o777")
```

```jsx
const ten1 = 10
const ten2 = 10n

console.log(ten1 == ten2) // true
console.log(ten1 === ten2) // false
```

# 注意不能混用

```jsx
// console.log(ten2 * 1) // TypeError: Cannot mix BigInt and other types, use explicit conversions
console.log(ten2) // 10n
console.log(Number(ten2)) // 10
console.log(ten2 * 1n)
console.log(ten2 * BigInt(1))

// Math API 不支持 BigInt
// console.log(Math.max(ten2, 100n)) // TypeError: Cannot convert a BigInt value to a number
```

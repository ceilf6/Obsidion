## 什么是HTML

根据W3C的规定：HTML 是用于描述页面结构的语言

结构：有什么东西、表示什么含义

Hyper Text Markup Language 超文本：强于普通文本，超链接

标记：有开始和结束 <> </>

MDN: Mozilla Developent Network

## 什么是CSS

根据W3C的规定：CSS是用于描述页面展示的语言

决定了页面长什么样子

查阅：MDN

## 执行 HTML, CSS

需要交给浏览器内核执行

像小程序、手机端运行：安装浏览器内核

### 浏览器组成

2. core: 内核
    1. JS执行引擎
    2. 渲染引擎

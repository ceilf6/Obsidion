# 事件

在React中，组件的事件，本质上就是一个需要**传递一个函数**的**属性**

```jsx
export default function Btn() {
    return (
        <button onClick={(e) => console.log("=== 我被电击了", e)}>
            点我
        </button>
    )
}
```

按照之前React对组件的约定，由于事件本质上是一个属性，因此也需要使用**小驼峰命名法**

**如果没有特殊处理，在事件处理函数中，this指向undefined**

需要使用组件的this上的方法，而不是事件处理函数中的（但是原型链是从当前往上找的，所以需要处理

1. 使用bind函数，绑定this
    
    一.
    
    ```jsx
    constructor(props) {
        super(props)
        this.handleClick = this.handleClick.bind(this)
    }
    ```
    
    二. 在使用时绑定
    
    ```jsx
    <button onClick={this.handleClick.bind(this)}>
    ```
    
2. 使用箭头函数：自动指向外层 this
    
    一. 事件处理函数不在原型上，而是在对象上
    
    ```jsx
    handleClick2 = () => {
        this.props.callback()
        this.props.onClick()
    }
    ```
    
    二. 在使用时
    
    ```jsx
    <button onClick={() => this.handleClick()}>
    ```
    

```jsx
export function Btn() {
    return (
        <button onClick={(e) => console.log("=== 我被电击了", e)}>
            点我
        </button>
    )
}

export class MyBtn extends React.Component {
    render() {
        return (
            <button onClick={this.props.callback}>
                点我
            </button>
        )
    }
}
```

```jsx
const callback = () => console.log("我被电击了")
const el = (
    <div>
        {Btn()}
        <MyBtn callback={callback} onClick={() => console.log("自定义组件的onClick")} />
    </div>
)
ReactDOM.render(el, document.getElementById('root'))
```

button 是 React 的内置组件，内部对事件进行了处理所以 onClick 会触发

自定义组件想要触发事件，得传递到能响应的元素上

```jsx
<h1 onClick={this.props.onClick}>点我</h1>
```

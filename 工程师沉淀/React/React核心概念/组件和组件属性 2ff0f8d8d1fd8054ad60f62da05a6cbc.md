# 组件和组件属性

React 元素

1. 组件元素 React Component Element
    
    开头大写
    
    ```jsx
    <Comp />
    ```
    
2. 内置元素 React Html Element
    
    开头小写
    
    ```jsx
    <div>
    <h1>
    <button>
    ```
    

组件：包含内容、样式和功能的UI单元

组件生成的仍然是React元素，变化的只是 type 值而已

![image.png](工程师沉淀/React/React核心概念/组件和组件属性/image.png)

所以得**通过首字母大写来区分是组件还是普通React元素**

## 创建一个组件

**特别注意：组件的名称首字母必须大写**

1. 函数组件

返回一个React元素

```jsx
export default function FuncComp() {
    return (
        <h1>nihao</h1>
    )
}
```

1. 类组件

必须 继承React.Component

必须提供 render函数 ，用于渲染组件

```jsx
import React from 'react'

export default class ClassComp extends React.Component {
    render() {
        return (
            <h1>nihao2</h1>
        )
    }
}
```

## 组件的属性

![image.png](工程师沉淀/React/React核心概念/组件和组件属性/image%201.png)

1. 对于函数组件，属性会作为一个对象的属性，传递给函数的参数
2. 对于类组件，属性会作为一个对象的属性，传递给**构造函数constructor**的参数
    
    ```jsx
    constructor(props) {
        super(props); // this.props = props
        console.log("=== props", props)
    }
    ```
    
    默认情况下直接不写即可
    
    使用时通过 this.props 拿到
    

注意：组件的属性，应该使用**小驼峰命名法**

之前学习的**React元素，本质上，就是一个组件（内置组件）**

**组件无法改变自身的属性**。

React中的哲学：**数据属于谁，谁才有权力改动**

改动第一层 props.att 会直接报错 readonly

改动 props.obj.att 不会报错，但是很危险！

因为到时候**排查**错误，如果数据组件是各自负责的话就很好找对应的组件即可，如果是随意改动那根本找不到源头

故而

**React中的数据，自顶而下流动**

# 传递元素内容

中间内容会自动带到 props.children 中

```jsx
import React from 'react';
import ReactDOM from 'react-dom';
import Comp from "./Comp"

ReactDOM.render((
    <Comp content1={<h2>第2组元素内容</h2>} content2={<h2>第3组元素内容</h2>}>
        <h2>第1组元素内容</h2>
    </Comp>
), document.getElementById('root'));

```

```jsx
import React from 'react'

export default function Comp(props) {
    console.log(props);
    return (
        <div className="comp">
            <h1>组件自身的内容</h1>
            {/* {props.children || <h1>默认值</h1>} */}
            {props.children}
            {props.content1}
            {props.content2}
        </div>
    )
}
```

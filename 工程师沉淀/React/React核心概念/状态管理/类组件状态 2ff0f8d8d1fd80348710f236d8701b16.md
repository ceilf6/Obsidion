# 类组件状态

类组件的状态本质就是 类组件实例对象上的一个**属性** **state对象**

组件状态：组件可以自行维护的数据

组件状态仅在类组件中有效

**状态初始化**

1. 构造函数

```jsx
constructor(props) {
    super(props)
    // 状态初始化
    this.state = {
    }
}
```

1. 或者直接

```jsx
state = {
    num: this.props.number
}
```

**状态的变化**

不能**直接改变状态：因为React无法监控到状态发生了变化**

必须使用 **this.setState({})** 改变状态

相当于 mixin : Object.assign()

一旦调用了this.setState，会导致当前组件重新渲染

**组件中的数据**

1. this.props：该数据是由组件的使用者传递的数据，所有权不属于组件自身，因此组件无法改变该数组
2. this.state：该数组是由组件自身创建的，所有权属于组件自身，因此组件有权改变该数据
    
    ⇒ 重新渲染
    

```jsx
import React from 'react'
// import { h1 } from 'framer-motion/client'
// 注意 tab 后可能会自动导入无关数据

export default class NumState extends React.Component {
    state = {
        num: this.props.number
    }
    constructor(props) {
        super(props)
        // 状态初始化
        // this.state = {
        //     num: this.props.number
        // }
        this.timer = setInterval(() => {
            if (!this.state.num) clearInterval(this.timer)
            this.setState({ num: --this.state.num }) // 通知 React 状态变化
            // Object.assign()
        }, 1000)
    }
    render() {
        return (
            <h1>{this.state.num}</h1>
        )
    }
}
```

像层级嵌套的话，上层数据变化导致重新渲染时，下层也会随之re-render

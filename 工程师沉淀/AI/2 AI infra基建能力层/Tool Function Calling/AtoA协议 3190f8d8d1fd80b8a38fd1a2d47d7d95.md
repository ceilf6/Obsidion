# AtoA协议

协议 本质就是 **约定规范**

Agent to Agent Protocol

让多个 Agent 能够标准化通信、协作、分工、评估

## 核心组件

1. Agent Identify
    
    每个 Agent 的唯一**身份标识**
    
    ```
    agent_id
    agent_type
    capabilities
    version
    ```
    
    ```json
    {
      "agent_id": "dev_agent_001",
      "capabilities": ["code_generation"],
      "version": "1.0"
    }
    ```
    
2. Agent 通信必须要有统一**消息结构**
    
    ```json
    Envelope
     ├ sender
     ├ receiver
     ├ message_type
     ├ payload
     └ metadata
    ```
    
    ```json
    {
      "sender": "dev_agent",
      "receiver": "review_agent",
      "type": "code_review_request",
      "payload": {
        "code": "...",
        "language": "typescript"
      },
      "metadata": {
        "task_id": "123",
        "timestamp": 1710000000
      }
    }
    ```
    
3. 消息类型
    
    task_request 请求执行任务
    
    task_result 返回结果
    
    evaluation 评分
    
    feedback 改进建议
    
    error 错误
    
    status 状态更新
    
4. Task Context
    
    Agent 需要共享上下文
    
    ```json
    task_id
    parent_task
    history
    artifacts
    ```
    
    例如
    
    ```json
    任务：生成 React Hook
    开发Agent：完成代码
    评价Agent：评分
    修复Agent：优化代码
    ```
    
    ```json
    {
      "task_id": "react_hook_001",
      "artifacts": {
        "generated_code": "...",
        "prompt": "...",
        "constraints": ["typescript"]
      }
    }
    ```
    
5. **能力**发现
    
    Agent 需要知道谁可以做什么任务
    
    通常通过 registry 类似于服务注册中心
    
    例如
    
    ```json
    agent_registry
      ├ dev_agent
      ├ review_agent
      ├ test_agent
    ```

# **Agent Loop（自我优化）**

很多 Agent 系统会加入 **self-improvement loop**

```
DevAgent
  ↓
ReviewAgent
  ↓
score < threshold ?
  ↓ yes
FixAgent
  ↓
ReviewAgent
  ↓
score >= threshold
```

流程：

```
generate
   ↓
evaluate
   ↓
improve
   ↓
evaluate
```

这叫：

**Reflexion Loop**

# **最简单 A-to-A 实现（JS示例）**

你其实可以写一个简单的 message bus：

```
class AgentBus {
  agents = {}

  register(agent) {
    this.agents[agent.id] = agent
  }

  async send(msg) {
    const agent = this.agents[msg.receiver]
    return agent.handle(msg)
  }
}
```

Agent：

```
class DevAgent {
  async handle(msg) {}

  async generate() {
    const code = "function sum(a,b){return a+b}"

    return bus.send({
      sender: "dev",
      receiver: "review",
      type: "evaluate",
      payload: { code }
    })
  }
}
```

ReviewAgent：

```
class ReviewAgent {
  async handle(msg) {
    if (msg.type === "evaluate") {
      return {
        score: 8,
        feedback: "add types"
      }
    }
  }
}
```

# **为什么 A-to-A 很重要**

如果没有 A-to-A：

```
Agent
  ├ generate
  ├ evaluate
  ├ test
  └ fix
```

会变成 **巨型 agent**。

有 A-to-A：

```
Planner
Developer
Reviewer
Tester
Fixer
```

优点：

- 模块化
- 可扩展
- 可并行
- 可替换

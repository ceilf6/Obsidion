# 测试文件书写

这个模块/函数/组件在什么场景下，
输入什么，
应该得到什么结果？

```jsx
describe('某个功能', () => {
  it('在某种条件下，应该产生某种结果', () => {
    // 准备
    // 执行
    // 验证
  })
})
```

```jsx
import { 被测对象 } from './被测对象'

describe('被测对象名称', () => {
  it('should do something when condition is met', () => {
    // Arrange
    const input = ...

    // Act
    const result = 被测对象(input)

    // Assert
    expect(result).toBe(...)
  })

  it('should handle edge case', () => {
    // ...
  })
})
```

```jsx
Jest
Vitest
Mocha
Playwright
Cypress
```

# 采样策略API - 概率

https://github.com/ceilf6/FrontAgent/commit/d71a4e784f7df18686cc3c8c7831f29f8d275951

和大模型打交道的关键在于控制其运行核心的**随机**性（生成词的概率分布）

## 贪心解码

直接告诉大模型不要概率选择，而是只选择最高概率的

缺点是让输出的鲁棒性下降

## 温度 temperature

通过 temperature 控制**随机性**

温度更高导致输出随机性更高，鲁棒性（模型在输入变化下还能不能稳定表现）下降

温度为0就是贪心解码

# Top_K

只选择概率最高的k个

# Top_P

只选择概率前p%的

# repetition_penalty

控制重复生成，**对“已经生成过的 token”要不要降权**

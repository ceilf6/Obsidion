# 大模型的3D并行

很好，我们把 **数据并行、模型并行、流水线并行**放在一张图里理解（这也是大模型训练最常见的 **3D并行**）。

---

# **一张图看懂三种并行**

```
                 大模型训练并行策略
                       │
        ┌──────────────┼──────────────┐
        │              │              │
     数据并行        模型并行        流水线并行
   (Data Parallel) (Model Parallel) (Pipeline Parallel)
```

---

# **1️⃣ 数据并行（Data Parallel）**

**切分的是：数据**

每个 GPU 都有 **完整模型**，但处理 **不同数据**。

```
        模型复制
GPU1  [完整模型]  ← 数据1
GPU2  [完整模型]  ← 数据2
GPU3  [完整模型]  ← 数据3
GPU4  [完整模型]  ← 数据4
```

训练流程：

```
forward
backward
梯度同步（AllReduce）
更新模型
```

特点：

- 实现简单
- 最常见
- 模型必须能放进单个GPU

---

# **2️⃣ 模型并行（Model Parallel）**

**切分的是：模型参数**

不同 GPU 存 **不同层**。

```
输入
 │
 ▼
GPU1  Layer1–Layer4
 │
 ▼
GPU2  Layer5–Layer8
 │
 ▼
GPU3  Layer9–Layer12
 │
 ▼
GPU4  Layer13–Layer16
 │
 ▼
输出
```

特点：

- 解决 **模型太大放不下 GPU**
- 需要 GPU 之间通信

---

# **3️⃣ 流水线并行（Pipeline Parallel）**

**核心：让不同阶段同时工作**

把模型分层后，再让 **多个 micro-batch 同时流动**。

时间轴：

```
时间1  batch1 → GPU1

时间2  batch1 → GPU2
       batch2 → GPU1

时间3  batch1 → GPU3
       batch2 → GPU2
       batch3 → GPU1
```

最终状态：

```
GPU1 GPU2 GPU3 GPU4
  │   │   │   │
 b4  b3  b2  b1
```

每个 GPU 都在忙。

---

# **4️⃣ 三种并行对比**

| **并行方式** | **切分对象** | **目的** |
| --- | --- | --- |
| 数据并行 | 数据 | 提高训练速度 |
| 模型并行 | 模型参数 | 解决模型太大 |
| 流水线并行 | 计算阶段 | 提高设备利用率 |

---

# **5️⃣ 大模型真正使用的是：3D并行**

GPT / LLaMA 训练通常是：

```
        数据并行
            │
     ┌──────┴──────┐
     │             │
  流水线并行    张量/模型并行
```

例如：

```
2048 GPUs
 = 8 (pipeline)
 × 8 (tensor parallel)
 × 32 (data parallel)
```

这就是 **Megatron-LM / DeepSpeed 的核心设计**。

---

✅ **一句话总结**

```
数据并行：切数据
模型并行：切模型
流水线并行：切计算阶段
```

三者结合就是 **大模型训练的3D并行架构**。

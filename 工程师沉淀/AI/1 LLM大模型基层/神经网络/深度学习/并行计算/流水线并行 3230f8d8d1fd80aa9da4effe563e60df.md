# 流水线并行

**流水线并行（Pipeline Parallelism）** 是一种并行计算方式，其核心思想是：

> **把一个计算任务按步骤（阶段）拆分，不同阶段在不同计算设备上执行，并像流水线一样同时处理不同数据。**
> 

---

## **1️⃣ 用生活例子理解**

类似 **工厂流水线**：

生产一辆车需要 4 个步骤：

1. 安装底盘
2. 安装发动机
3. 安装车门
4. 喷漆

如果只有一个人做：

```
车1：步骤1 → 步骤2 → 步骤3 → 步骤4
车2：步骤1 → 步骤2 → 步骤3 → 步骤4
```

效率很低。

如果采用 **流水线并行**：

| **工人** | **工作** |
| --- | --- |
| 工人1 | 步骤1 |
| 工人2 | 步骤2 |
| 工人3 | 步骤3 |
| 工人4 | 步骤4 |

执行过程：

```
时间1：车1-步骤1
时间2：车1-步骤2，车2-步骤1
时间3：车1-步骤3，车2-步骤2，车3-步骤1
...
```

多个产品 **同时在不同阶段加工**。

---

## **2️⃣ 在深度学习中的流水线并行**

在训练大型模型时，模型层数很多，可以把 **模型按层拆分到不同GPU**：

示例：

```
GPU1：Layer1–Layer4
GPU2：Layer5–Layer8
GPU3：Layer9–Layer12
GPU4：Layer13–Layer16
```

训练时：

1. **输入数据被分成多个 micro-batch**
2. 每个 GPU 只计算自己负责的层
3. 数据在 GPU 之间依次传递

流程类似：

```
microbatch1 → GPU1 → GPU2 → GPU3 → GPU4
microbatch2 → GPU1 → GPU2 → GPU3 → GPU4
```

这样不同 GPU 可以 **同时工作**。

---

## **3️⃣ 为什么需要流水线并行**

主要用于 **超大模型训练**：

当模型 **一张 GPU 放不下** 时：

- **数据并行**：复制模型（不行，因为模型太大）
- **模型并行**：拆分模型
- **流水线并行**：让模型拆分后还能高效并行

---

## **4️⃣ 三种并行方式对比**

| **并行方式** | **切分对象** | **特点** |
| --- | --- | --- |
| 数据并行 | 数据 | 每个GPU都有完整模型 |
| 模型并行 | 模型参数 | 不同GPU存不同层 |
| 流水线并行 | 模型阶段 | 不同阶段并行执行 |

---

✅ **一句话总结**

> 流水线并行是把模型计算过程分成多个阶段，放在不同设备上执行，让不同数据在这些阶段中像流水线一样流动，从而提高训练效率。
>

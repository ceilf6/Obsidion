# 工作流程

当前 `FrontAgent`（`frontagent run`）工作流程可以概括为 8 步：

1. CLI 解析任务与参数，组装 LLM 配置，创建 Agent，并注册 `file/web/shell` MCP 客户端（Shell 命令需人工批准）。
    
    [apps/cli/src/index.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/apps/cli/src/index.ts)
    
2. Agent 创建任务上下文，**加载 SDD 约束**，进入执行入口。
    
    [packages/core/src/agent.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/agent.ts)
    
3. 规划前预扫描项目文件，并自动检测 dev server 端口（给后续浏览器验证用）。
    
    [packages/core/src/agent.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/agent.ts)
    
4. Planner 生成执行计划（优先 LLM，两阶段：**先大纲再展开**），并保留 phase 字段。
    
    [packages/core/src/planner.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/planner.ts)
    
    [packages/core/src/llm.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/llm.ts)
    
5. 计划生成后，若检测到代码变更步骤且存在验收步骤，会自动追加 `阶段7-仓库管理`（git/gh）。
    
    [packages/core/src/planner.ts:144](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/planner.ts:144)
    
    [packages/core/src/planner.ts:421](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/planner.ts:421)
    
6. Executor 按阶段、按依赖执行步骤；对 `create_file/apply_patch` 可动态生成代码后再落盘。
    
    [packages/core/src/executor.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/executor.ts)
    
7. 每阶段结束会做检查（模块依赖、缺失 npm 依赖、TS 检查、代码质量 SubAgent）；若失败，进入错误反馈循环自动生成修复步骤并重试。
    
    [packages/core/src/agent.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/agent.ts)
    
    [packages/core/src/llm.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/llm.ts)
    
8. 全部阶段结束后输出结果摘要，清理上下文与事实缓存。
    
    [packages/core/src/agent.ts](https://www.notion.so/Users/a86198/Desktop/Lab/AI/3-Application/FrontAgent-app/packages/core/src/agent.ts)
    

当前阶段集合：`阶段1-分析 -> 阶段2-创建 -> 阶段3-安装依赖 -> 阶段4-验证 -> 阶段5-启动 -> 阶段6-浏览器验证 -> 阶段7-仓库管理（新增）`。

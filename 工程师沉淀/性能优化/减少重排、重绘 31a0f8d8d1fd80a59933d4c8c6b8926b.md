# 减少重排、重绘

首先，浏览器渲染流程是

[浏览器渲染流程](浏览器渲染流程%202f70f8d8d1fd80d5a582c918abb221ef.md) 

```jsx
DOM -> CSSOM -> Render Tree -> Layout(重排) -> Paint(重绘) -> Composite
```

# 重排

## 原因

变更了元素的几何属性

```jsx
offsetWidth
offsetHeight
offsetTop
offsetLeft

scrollTop
scrollHeight

getComputedStyle()

getBoundingClientRect()
```

## 优化思路

1. **统一批量修改** DOM
    
    ```jsx
    div.style.cssText = `
      width:100px;
      height:200px;
    `
    ```
    
    或者例如通过 class 统一修改样式
    
    ```jsx
    div.classList.add("active")
    ```
    
2. DOM 离线操作
    
    利用 **DocumentFragment**
    
    ```jsx
    const frag = document.createDocumentFragment()
    
    for (let i = 0; i < 1000; i++) {
      const li = document.createElement("li")
      frag.appendChild(li)
    }
    
    ul.appendChild(frag)
    ```
    
3. 避免读写交替
    
    因为读取时会强制立马布局，如果不读的话浏览器会通过合并操作进行性能优化
    
    ```jsx
    div.style.width = "100px"
    console.log(div.offsetWidth)
    
    div.style.width = "200px"
    console.log(div.offsetWidth)
    ```
    
    最好是在写后统一读
    
    ```jsx
    div.style.width = "100px"
    div.style.height = "200px"
    
    const width = div.offsetWidth
    const height = div.offsetHeight
    ```
    
4. 使用 transform / opacity
    
    如果直接修改元素的属性会触发布局
    
    但是 transform 和 opacity 是属于 最后GPU合成线程中的
    
5. 使用 visibility / opacity 替代 display
6. 元素开启 定位，减少属性变化后的影响范围
7. 使用 contain 限制影响范围
    
    ```jsx
    contain: layout
    ```
    
    **该元素布局不会影响外部**
    
8. 开启 will-change
    
    ```jsx
    will-change: transform
    ```
    
    提前创建合成层
    
9. 列表相关 虚拟列表
10. 避免频繁 setState 导致的子树重新布局
11. key 稳定，提高复用率，避免重新创建

# 重绘

1. 减少触发重绘的样式修改
    
    ```jsx
    color
    background
    border-color
    box-shadow
    text-shadow
    visibility
    outline
    ```
    
2. 减少重绘区域
    
    ```jsx
    body.style.background = "red"
    ```
    
    优化成
    
    ```jsx
    container.style.background = "red"
    ```
    
3. 使用 transform / opacity
    
    避免 paint
    
    很多动画用
    
    ```jsx
    left
    top
    width
    height
    ```
    
    会触发 layout+paint
    
    而用 transform / opacity 只需要 composite ，GPU直接处理
    
4. 使用 visibility / opacity 替代 display

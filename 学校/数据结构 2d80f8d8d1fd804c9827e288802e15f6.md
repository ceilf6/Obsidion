# 存储密度

数据元素本身所占存储空间/数据结构所占的空间

## 顺序存储

**特点：**

- 所有元素**连续存放**
- **不需要额外指针**

存储密度接近 100%

## 链式存储

以**单链表**为例：

- 数据域：d 字节
- **指针域**：p 字节

单个即诶单占

```cpp
d + p
```

存储密度

```cpp
d / (d + p) < 1
```

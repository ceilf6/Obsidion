## 参数传递

函数调用传递给形参表的实参在类型、个数和顺序上必须保持一致，C++中函数的参数传递由四种方式

1. 值参数传递
缺省的参数传递方式，实参的值传递给形参对应的**局部工作区**的单元，所以**不会改变实参的值**
2. 引用参数传递
**参数名前加上 &** ，被传递的不是实参的值，而是实参的地址，会影响实参对应的内存空间
函数只能返回一个值，所以如果需要修改多个值可以用引用的方式进行修改
    
    ```cpp
    void change(int &a2, int &b2)
    {
        a2 = 10;
        b2 = 20;
    }
    
    int main()
    {
        int a = 1;
        int b = 2;
        change(a, b); // 引用传递仍然是变量名
    ```
    
3. 常值参数传递
const int a
4. 常值引用参数传递

# 联合

联合 union 是一种变量，可以在不同时间内维持不同类型和不同长度的对象

提供给了在单个存储区域中操作不同类型数据的方法

> 多个成员共用一块内存，同一时刻只能安全地使用其中一个成员
> 

```cpp
union U {
    int i;
    double d;
    char c;
};
```

这块内存区域的大小 = 最大成员的大小

| struct | 每个成员都有自己的内存 |
| --- | --- |
| union | 所有成员**重叠**在同一地址 |

联合无法知道当前有效的是谁

解决方案： 联合 + 标记

```cpp
enum Type { INT, DOUBLE };

struct Value {
    Type type;
    union {
        int i;
        double d;
    };
};
```

## 多态

多态成立的三个条件

1. 有继承关系
2. 基类中有虚函数
3. 使用基类**指针** / 引用指向派生类对象

通过对象中隐藏的虚表指针，在运行时根据对象的实际类型选择函数地址

虚函数（virtual function）和多态性（polymorphism）使得设计和实现易于扩展的系统成为可能。在程序开发中，　不论类是否已经建立，程序员都可以利用虚函数和多态性先编写处理这些类的对象的程序。如果有些类要从基类派生，那么程序可以提供操作基类对象的通用框架，然后由派生类对象对该框架作很好的加工。

### 动态联编

方法调用在运行时根据对象的实际类型来决定，而不是在编译时决定

传统软开中对于复杂解耦一般是通过算法分解，例如 PASCAL中的过程、FORTRAN中的子程序和C语言中的函数

面向对象的程序设计技术建立在对象分解的基础上，以类设计为核心，面向对象分解将软件看成由良好定义的对象组成的集合，这些对象是应用领域中实体的**模块化**体现，

**将系统分解为若干对象后，再去考虑功能分解**

## 虚函数

在基类中用 **virtual** 关键字声明的成员函数，允许在运行时根据对象的实际类型决定调用哪个函数

普通成员函数是静态编译的，虚函数是运行期动态联编

```cpp
class Base {
public:
    virtual void f() {}
};

class Derived : public Base {
public:
    void f() override {}
};

Base* p = new Derived();
p->f();   // 调用 Derived::f()
```

## 继承

```cpp
class Point
{
    friend ostream &operator<<(ostream &, const Point &);

public:
    Point(float = 0, float = 0); // 默认的构造函数
    void setPoint(float, float); // 设置坐标值
    float getX() const { return x; }
    float getY() const { return y; }

protected:      // 允许派生类访问
    float x, y; // 点（类Point的对象）的x和y坐标
};
```

friend 授予 **函数** 或 **类** 访问权限

友元可以访问类的 private 和 protected 成员，此处赋予了操作符 << 访问 x 和 y 成员的权利

protected 是受保护、给**子类**用的

```cpp
class Circle : public Point
{
    friend ostream &operator<<(ostream &, const Circle &);

public:
    Circle(float r = 0.0, float x = 0, float y = 0);
    void setRadius(float);   // 设置半径值
    float getRadius() const; // 返回半径值
    float area() const;      // 计算圆的面积
protected:
    float radius;
};
```

: 冒号后面是基类列表

```cpp
class 派生类名 : 继承方式 基类名
```

### 继承方式

下面说明的 B 都是派生类名， A 是基类名

1. public 继承
派生类是一个基类
支持
    
    ```cpp
    A* p = new B()
    ```
    
2. protected
基类的 public 成员在派生类中会变成 protected
3. private
实现复用
派生类用了基类的实现，但不是基类，不允许 A* p = new B()

// 先用成员初始化值调用类Point的构造函数，
// 然后再调用类Circle的构造函数初始化半径值

```cpp
Circle::Circle(float r, float a, float b)
    : Point(a, b) // 调用基类的构造函数
{
    radius = r;
}
```

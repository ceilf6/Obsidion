# self-微调

1. 把 frontagent-planner/ 文件夹推到 GitHub（或打包 zip）
2. 在 Colab 中选择 T4 GPU 运行时
3. 打开 colab_train.ipynb，按顺序执行 3 个 cell：
- 训练 → [train.py](http://train.py/)（~15-30 分钟）
- 评估 → [eval.py](http://eval.py/)（JSON 合法率、计划完整性）
- 发布 → [publish.py](http://publish.py/)（推送至 ceilf6/frontagent-planner-1.5B）

注意 token 的权限

❯ 为什么我已经微调了模型还是要在系统提示词里面强调？

⏺ 好问题。原因是：

训练数据的格式是 instruction + input → output，其中 instruction 就是那个系统提示词。模型学的是 "在这个提示词下，给这个 input
输出什么"。所以推理时需要保持和训练时一致的输入格式，否则模型会"困惑"
